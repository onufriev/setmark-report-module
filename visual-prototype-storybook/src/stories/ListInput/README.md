# ListInput
Компонент для ввода списка значений.
Главное отличие от предыдущей версии - работает с массивом строк.

Точки ввода:
1. Корневое поле ввода RootTextInput;
2. Поле ввода списка значений ListTextInput.

## Параметр delimiter
Используется внутри компонента. Является дополнительным разделителем.
Первичный разделитель - перенос строки `\n|\r|\r\n`.

## Фильтрация и обработка ввода
Введенное значение обрабатывается в следующем порядке:
1. Строка разбивается на массив по разделителю и переносу строк;
2. У каждого значения удаляются пробелы по краям (отлючается параметром `entryTrimDisabled`);
3. Дополнительно значения можно отфильтровать по регулярному выражению `entryRegExp`;
4. Все пустые значения отбрасываются.

На последующую этапы передаются **уникальные** значения ввода.
В окне ввода показываются два счётчика.
Поле "сейчас в списке" содержит общее число введенных значений, прошедших первичную обработку.
Поле "дубликатов" содержит число повторяющихся значений. Следовательно уникальных будет "общее" минус "дубликатов".

## Валидация
Для анализа пользовательского ввода можно назначить функцию в параметре `validator`.
Валидатор поддерживает прерывание. Можно использовать abortSignal в методах проверки.

## С постобработкой валидации
Компонент предлагает пользователю обработать некорректные значения, о которых сообщил `validator`.
Добавленные исправленные значения снова пройдут валидацию той же функцией и добавятся к уже имеющимся в компоненте.
Отключить постобработку можно с помощью `postProcessingDisabled`.

## С параметром clearAfterApply
В случае использовани неконтролируемого варианта компонента будет полезно использовать параметр `clearAfterApply`,
который очищает внутренне состояния после эмиттинга введенных значений.

## С параметром clearable
Позволяет очищать данные компонента. Вызывает onChange с пустым массивом.

## Параметр getEntryTypeText
В названии заголовков, надписях и прочих местах подразумевается указание локализованной "сущности".
Например, "Список __штрихкодов__". Данный параметр `getEntryTypeText` принимает функию получения этой фразы.
В параметр передаётся количество сущностей, для составления правильной формы множественного числа.

## Переопределение текстом
Все тексты можно переопределить через параметр `textOverrides`.

## Кастомный корневой элемент
Корневой элемент можно изменить. Параметр `children` является рендер-функцией.
Достаточно назначить метод `open` на выбранное событие своего компонента.
