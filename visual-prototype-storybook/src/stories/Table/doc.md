# Группировка

Во всех случаях производится преобразование данных строк в иной формат, универсальный для всех подвидов, но с разными параметрами.
Главный принцип - данные рисуются в строке. Если включена виртуализация, должна задаваться высота.

## 1. По полю

Поле(я), по которым формируется группировка данных указывается в `groupingField(s)`.

Вид рендеринга:

| ячейка группы 1 |                 |                 |  <--- агрегирующая строка группы
|                 | ячейка строки 2 | ячейка строки 3 |  <--- 1 строка данных группы
|                 | ячейка строки 2 | ячейка строки 3 |  <--- 2 строка данных группы

Наличие валидного `groupingField(s)` инициализирует режим группировки.
В `TableColumnProps` указывается `renderGroupCell`, в параметрах передаётся массив вложенных строк (для агрегации данных).
Рендеринг ячейки, по которой производится агрегация, производится стандартным способом: либо по полю, либо через renderCell.
Если задан `renderGroupCell`, по нему будет произведен рендеринг ячейки в строке группы.
Высота строки подчиняется общему правилу.
Есть возможность задать высоту группировочных строк `getRowGroupHeight`.

## 2. Кастомный рендер вложенных данных (details)

Формат: стандартная строка -> кастомный details.
`renderRowDetails`
`getRowDetailsHeight`

внутрянка - дополнительный элемент, в отдельной колонке

есть подсмотренная идея выводить такие элементы как колонку с особым значением в type

```js
{
    userId: 1,
    details: {
        firstName: 'Dmitry',
        lastName: 'Markov',
    }
}
```
