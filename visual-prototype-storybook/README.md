# visual-prototype-storybook

Автономная копия Storybook из `CSI_UI` v1.31.2 с экранными stories Set Mark: обзор, инциденты, необходимые действия, аналитика и настройки.

## Запуск

```bash
npm install
npm run storybook
```

Откройте `http://localhost:6006/` и выберите `Set Mark / Screens / Overview`.

Папка содержит собственную копию `src` и `.storybook`. При редком обновлении `CSI_UI` достаточно повторить копирование исходников и перенести stories из `src/setmark`.
