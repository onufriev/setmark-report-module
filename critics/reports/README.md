# Отчёты критиков

Сюда сохраняются рабочие отчёты critic agents, запущенных по явному выбору Product Manager. Имя файла:

`<phase>-<critic>-report.md`

Примеры:

- `product-definition-vera-report.md`
- `visual-prototype-nora-report.md`
- `working-prototype-kane-report.md`

Отчёт критика не заменяет официальный phase review в корневой папке `reports/`. Критик находит риски; переход этапа по-прежнему оформляется штатными инструментами Product Compiler.
