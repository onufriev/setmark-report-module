# Claude project configuration

- `commands/` — команды основного процесса Product Compiler.
- `skills/` — необязательные критики для Claude Code и других сред Claude, поддерживающих project skills.

Критики нельзя запускать автоматически. Сначала Product Manager должен согласиться на дополнительную проверку либо напрямую вызвать конкретный skill. Универсальные исходные инструкции критиков находятся в `critics/agents/`.
