# Контрольный отчёт: VISUAL_VALIDATION

**Продукт:** Мониторинг и анализ нарушений в Set Mark  
**Редакция:** R1  
**Статус:** Готово к проверке Product Manager  
**Дата:** 2026-09-01

## Суть этапа

В рамках визуальной валидации прототип приведён к объединённым требованиям из PR #10. Прототип показывает структуру продукта Set Mark, различает лицензионные и ролевые состояния, учитывает страну организации и демонстрирует подключение к Честному знаку с использованием ЭЦП.

## Основные изменения

- Верхнеуровневая структура: «Обзор», «Журнал нарушений», «Мониторинг маркировки» и «Настройки».
- Внутри Мониторинга: «Инциденты», «Необходимые действия» и «Аналитика».
- Администратор системы может просматривать Журнал нарушений при наличии базового права ЖН.
- Добавлен переключатель демонстрационных сценариев доступа: действующая лицензия, несоответствие, льготный период, отсутствие и окончание лицензии, неизвестный статус с историей и без неё, отсутствие права ЖН и страна не `RU`.
- Ограниченный режим показывает только агрегаты Честного знака без строк, карточек, рекомендаций и данных ЖН.
- Недоступные разделы открывают лицензионные заглушки без утечки деталей.
- Для страны не `RU` пункты Мониторинга скрываются, прямые переходы не раскрывают данные, ЭЦП отсутствует.
- В Настройках добавлено подключение Честного знака с использованием ЭЦП.
- Срок хранения ограничен 30 днями.
- CSV текущей выборки содержит 23 согласованные колонки, включая риск автоштрафа и потенциальную сумму штрафа.
- Поиск выполняется по точному штрихкоду, артикулу и полному коду маркировки; несколько значений разделяются запятыми.
