# Контрольный отчёт: VISUAL_PROTOTYPE

**Продукт:** модуль отчёта по нарушениям Set Mark  
**Редакция:** R4  
**Статус:** Готово к проверке Product Manager  
**Дата:** 2026-08-31

## Суть этапа

R4 основан на исправленном `VISUAL_PROTOTYPE-R3` и учитывает последнее замечание Product Manager: из верхней панели удалён селектор «Сеть „Север“», поскольку в согласованных требованиях текущего MVP нет сценария переключения между несколькими торговыми сетями или организациями.

Это изменение не затрагивает требования к фильтрации по магазинам внутри доступной пользователю организации и не меняет остальные функции R3.

## Изменение после R3

- Удалён выпадающий селектор «Сеть „Север“» из верхней панели.
- Прототип больше не создаёт ложное ожидание мультисетевого режима.
- Верхняя панель содержит бренд Set Mark и профиль пользователя; выбор организации в текущем MVP не моделируется.

## Сохранённые исправления R3

### Дашборд

- Блок «Объекты с наибольшим риском» с переходом к критическим инцидентам магазина.
- Блок «Состояние данных» с двумя сигналами: последнее обращение за отчётом Честного Знака и связь с Set Centrum.
- Показатели, диаграмма типов и необходимые действия пересчитываются по выбранному периоду.

### Аналитика

- Фильтры «Только критические» и «Только подтверждённые нарушения».
- Показатели «Инциденты», «Критические», «Подтверждённые нарушения» и «Группировка».
- Автоматическая группировка по дням/неделям и кликабельные колонки графика.

### Инциденты и карточка

- Поиск по штрихкоду, артикулу и полному коду маркировки, включая несколько значений через запятую.
- Множественный выбор магазинов.
- CSV текущей выборки из 21 согласованного поля.
- Рабочие PDF демонстрационных инцидентов.
- Потенциальный штраф остаётся в UI и не дублируется отдельным признаком риска.

### Настройки

- Ежедневные уведомления.
- Срок хранения данных.
