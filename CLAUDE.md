# Product Compiler для Claude

Прочитай `PRODUCT-COMPILER.md` до начала работы.

- основа требований — законченные пользовательские сценарии;
- не создавай отдельное требование из каждого ответа Product Manager;
- служебные основания храни в невидимых метаданных и реестрах;
- блокируют работу только пробелы в видении, границах и основном сценарии;
- неблокирующие вопросы можно оставить открытыми;
- не предлагай архитектуру или техническое развитие;
- прототипы необязательны, выбранная ветка фиксируется отдельно;
- стек и источник данных обязательны только для рабочего прототипа;
- отчёты создаются только в `reports/` через `finalize_phase_review.py`;
- состояние пересчитывается через `sync_workspace.py`.

Критики необязательны. Перед завершением значимого этапа один раз предложи
подключить подходящего критика. Отказ не блокирует этап и не считается риском.

При просьбе перезапустить процесс после изменения прочитай
`internal/restart-process.md`, выполни анализ влияния и продолжи с первого
затронутого этапа.
