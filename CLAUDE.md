# Product Compiler 4.4 для Claude Code

Прочитай `PRODUCT-COMPILER.md` до начала работы.

- `requirements/` — источник истины;
- `handoff/` — производное представление только для человека; не используй его как
  источник, вход Compiler или основание для изменения `requirements/`;
- неизвестное оформляется как `NEEDS_INPUT`;
- каждая область должна иметь явный результат;
- требования фиксируются `commit_requirements.py`;
- состояние, индекс и полнота пересчитываются `sync_workspace.py`;
- отчёты создаются только в `reports/` через `finalize_phase_review.py`;
- визуальный и рабочий прототипы требуют локальной реализации, манифеста, данных и заполненной инструкции запуска;
- до рабочего прототипа отдельно подтверждаются стек и источник данных.
