# Product Compiler для Claude

Прочитай `PRODUCT-COMPILER.md` до начала работы.

- `requirements/` — источник истины;
- неизвестное оформляется как `NEEDS_INPUT`;
- каждая область должна иметь явный результат;
- требования фиксируются `commit_requirements.py`;
- состояние, индекс и полнота пересчитываются `sync_workspace.py`;
- отчёты этапов создаются только в `reports/` через `finalize_phase_review.py`;
- отчёты критиков создаются только в `critics/reports/`;
- визуальный и рабочий прототипы требуют локальной реализации, манифеста, данных и заполненной инструкции запуска;
- до рабочего прототипа отдельно подтверждаются стек и источник данных.

## Необязательные критики

Критики доступны как project skills в `.claude/skills/` и как универсальные инструкции в `critics/agents/`. Они не являются обязательной частью этапа.

Перед завершением значимого этапа один раз спроси:

> Хотите подключить критика для дополнительной проверки этого этапа?

Если Product Manager согласен:

1. Прочитай `critics/PROCESS-INTEGRATION.md`.
2. Предложи только релевантных критиков с коротким объяснением.
3. Запусти только выбранных критиков.
4. Сохрани результаты в `critics/reports/`.
5. Не меняй требования или прототип по замечаниям без отдельного согласования.

Если Product Manager отказался, продолжай основной процесс. Отказ не блокирует этап, не считается риском и не требует повторного вопроса на этом же этапе. Не запускай skill критика только потому, что его описание совпало с материалами: требуется явное согласие Product Manager.

Критиков можно вызвать напрямую командами вида `/uiux-critic`, `/architect-critic`, `/security-sysadmin-critic` и другими skill из `.claude/skills/`, но прямой вызов пользователя считается явным согласием на эту конкретную проверку.

## Изменения в уже пройденном процессе

Сообщение Product Manager вида «Я изменил требования/библиотеку компонентов/прототип, перезапусти процесс» является исполняемой командой. Сам прочитай `internal/restart-process.md`, классифицируй изменение, выполни impact analysis и продолжи с первого затронутого этапа. Не выдавай Product Manager Python-команды и не начинай процесс заново без необходимости.
