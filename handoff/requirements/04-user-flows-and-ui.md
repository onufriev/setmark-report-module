# Пользователи, сценарии и интерфейс

## Пользователь и права

Функцией пользуется любой сотрудник, которому доступен текущий Журнал нарушений:
аналитик, товаровед, руководитель, администратор или владелец небольшой сети. Новая
роль не создаётся. Тот же пользователь может подключать True API, повторно проходить
авторизацию с УКЭП, запускать синхронизацию и менять критичность видов.

## Навигация MVP

Новая функциональность размещается в существующем интерфейсе Журнала нарушений и
содержит три рабочие зоны:

1. **Обзор** — период, состояние данных, основные агрегаты и распределение по видам.
2. **Инциденты** — строки отклонений, поиск, фильтры и группировки.
3. **Настройки** — подключения True API по ИНН, ручная синхронизация и критичность.

Существующий Журнал нарушений остаётся доступным в прежнем виде. Отдельные разделы
Аналитики и Необходимых действий не показываются.

## Основной путь

1. Пользователь открывает Обзор и выбирает период; по умолчанию используется неделя.
2. Сначала оценивает критичные отклонения и распределение по видам.
3. Нажатие агрегата, вида, магазина, кассы или товара открывает ровно соответствующую
   выборку Инцидентов.
4. Пользователь уточняет выборку поиском и фильтрами, при необходимости группирует по
   виду, магазину или товару.
5. Из строки открывает карточку и видит исходный результат ЧЗ и доступный кассовый
   контекст.
6. Возврат к списку сохраняет выбранные период и фильтры.

## Поиск и фильтры

Поиск принимает один или несколько разделённых запятыми штрихкодов, артикулов или
полных кодов маркировки. Значения объединяются по «ИЛИ», пробелы вокруг них
игнорируются. Магазины выбираются множественно, доступны «Выбрать все» и «Сбросить».
Период и фильтры согласованы между Обзором и списком.

## Карточка

В верхней части видны номер инцидента, дата, критичность, вид, магазин, касса и товар.
Блок ЧЗ показывает итоговый факт отклонения и исходные идентификаторы. Кассовая
цепочка визуально разделяет параллельные онлайн ЧЗ и Set Mark, последующий ЛМ ЧЗ,
решение ПО и действие кассы. Отдельно показываются ЖН, чек и настройки на момент
проверки. Недоступный источник обозначается без ложного вывода о причине.

## Визуальные и текстовые правила

Используются компоненты и паттерны `@crystalservice/csi_ui` в стилистике актуального
frontend Set Mark. Критичность не кодируется только цветом. Пользовательские тексты
русские, технические RA-коды и служебные статусы в интерфейс не выводятся. Ошибка
True API не содержит кнопку «Повторить» и предлагает зайти через некоторое время.
