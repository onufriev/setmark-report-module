# 6. Данные и интеграции

## Состав и происхождение данных

Нужны события отклонений «Честного знака», события и результаты проверок Set Mark, данные кассовых операций, магазинный контекст, полные коды маркировки, товарные и организационные идентификаторы, типы/результаты отклонений, временные метки и состояния обработки. Данные должны позволять сопоставить отклонение с сетью, магазином, кассой и товарной группой, построить агрегаты, аналитику, CSV и PDF.

Один инцидент соответствует одному отклонению; исходный снимок сохраняется. Повторные события дедуплицируются. Свежесть и полнота видны двумя сигналами состояния данных. Целевой срок появления инцидента — до 24 часов после получения события. Поддерживаются неполные, устаревшие и неизвестные данные без выдачи их за полный результат.

Трассировка: `REQ-DATA-001`, `REQ-DATA-002`, `REQ-DATA-003`, `REQ-DEC-018`, `REQ-DEC-038`, `REQ-DEC-039`, `REQ-DEC-091`, `REQ-BO-001`–`REQ-BO-003`.

## Интеграции и границы контрактов

Подтверждены получение отклонений через True API, получение событий Set Mark и использование контекста разрешительного режима. Канонические требования не задают конкретные production endpoint, формат API, авторизацию или хранилище; их нельзя выводить только из названий систем. Для ручной синхронизации используется существующая привилегия. Сбой внешнего источника должен приводить к видимой задержке/неполноте и журналированию, но не к потере исходных событий и не к влиянию на продажи.

Трассировка: `REQ-INT-001`, `REQ-INT-002`, `REQ-INT-003`, `REQ-DEC-032`, `REQ-DEC-075`, `REQ-DEC-096`, `REQ-DEC-099`, `REQ-BR-001`, `REQ-BR-002`.

## Вывод данных

CSV экспортирует текущую выборку в UTF-8, с русскими заголовками и российскими форматами, без отдельного поля риска автоштрафа и суммы потенциального штрафа. PDF отдельного инцидента содержит согласованный состав исходных данных, результат, объяснение, критичность, потенциальный штраф, Контур устранения, рекомендацию и полный код маркировки.

Трассировка: `REQ-FR-006`, `REQ-AC-001`, `REQ-DEC-037`, `REQ-DEC-039`, `REQ-DEC-071`, `REQ-DEC-072`.
