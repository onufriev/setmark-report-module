# 05. Данные и интеграции

## Получение отклонений True API

Set Mark получает сведения об отклонениях для ИНН клиента через метод True API
8.3.15.1 «Выгрузка сведений об отклонениях». В MVP запуск ручной: он доступен
пользователю с действующей УКЭП, административной привилегией настройки подключения
и доступом к выбранному ИНН. Автоматическая периодика нужна в будущем, когда появится
допустимая для 24/7 авторизация; текущий ingestion-контракт не должен этому мешать.

Для каждого отклонения обязателен raw snapshot, исходные наименования вида и
результата из `VIOLATIONS` CSV, версия справочника и состояние mapping. Неоднозначное
или отсутствующее сопоставление кодов не делает получение неуспешным: значения могут
быть `null`, а дальнейший анализ получает неизвестное значение.

## Данные для анализа

Для корреляции используются полный код маркировки, временная метка, данные Журнала
нарушений Set Mark и, когда доступно, последний результат проверки «Честного знака».
Данные кассовых проверок должны позволять отличить онлайн-проверку, последующую
офлайн-проверку и продажу без ответа обоих сервисов.

## Свежесть, полнота и хранение

- первые показатели появляются не позднее 24 часов после успешного подключения ЭЦП
  и первого доступного ответа источника;
- при первичной загрузке запрашивается доступная история, но не более 30 дней;
  неполный период показывает дату начала покрытия;
- до первых данных показывается состояние подключения и загрузки, а не нулевые
  показатели;
- целевое появление инцидента — не позднее 24 часов от получения события; в ручном
  MVP это эксплуатационная обязанность запуска не реже раза в сутки, не системная
  гарантия;
- срок хранения — 30 календарных дней либо меньшее настроенное значение; удалённые
  данные физически удаляются и не восстанавливаются.

Лицензионные ограничения меняют пользовательский доступ, но не останавливают
получение, обработку и хранение данных RU-клиента в пределах срока хранения.

## Выгрузки

PDF одного инцидента фиксирует факты, последовательность событий, результат и его
обоснование. В нём только название организации; не включаются рекомендации,
потенциальный штраф, подпись и специальное назначение в заголовке.

CSV содержит только выбранные пользователем данные, использует UTF-8 и корректно
открывается в российском Excel.

**Трассировка:** `REQ-INT-001`–`003`, `REQ-DATA-001`–`003`, `REQ-DEC-018`,
`REQ-DEC-039`, `REQ-DEC-063`–`070`, `REQ-DEC-088`, `REQ-DEC-096`–`099`.
