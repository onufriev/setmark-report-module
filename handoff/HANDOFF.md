# Передача продукта в разработку

Передаётся MVP Мониторинга маркировки Set Mark из двух самостоятельных выпусков:
контроля отклонений Честного знака и обогащённого разбора инцидента. Пакет также
содержит утверждённые требования следующего развития: автоматический анализ RA/INC,
рекомендации и Необходимые действия, Аналитику, CSV/PDF, email-дайджест, SetCentrum и
усечённый режим. Начальная точка — [DEVELOPER-START-HERE.md](DEVELOPER-START-HERE.md).
