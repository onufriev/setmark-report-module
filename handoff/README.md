# Передача в разработку

Откройте [DEVELOPER-START-HERE.md](DEVELOPER-START-HERE.md). Handoff собран вокруг
вопросов архитектора и лида: контекст, границы, модель, сценарии, данные, возможности,
ограничения и трассировка. Канонические требования используются для проверки деталей,
а не как обязательная последовательность чтения.

Этот каталог предназначен только для людей. Он является отражением канонических
требований и не используется Product Compiler или другим ИИ как источник фактов,
вход для валидации либо основание для изменения требований.
