# Передача в разработку

Откройте сначала [DEVELOPER-START-HERE.md](DEVELOPER-START-HERE.md). Вся информация, необходимая для реализации MVP, собрана в `handoff/`; искать базовую версию требований, отчёты или решения менеджера продукта не требуется.

## Состав handoff

- [01-product-and-domain.md](requirements/01-product-and-domain.md) — назначение продукта, границы MVP, объекты, роли, состояния и бизнес-правила.
- [02-functional-requirements.md](requirements/02-functional-requirements.md) — функциональность, данные и интеграции.
- [03-scenarios.md](requirements/03-scenarios.md) — пользовательские, бизнес-, системные, исключительные и эксплуатационные сценарии.
- [04-quality-and-constraints.md](requirements/04-quality-and-constraints.md) — нефункциональные требования, локализация, доступность, оборудование и технические ограничения.
- [05-acceptance.md](requirements/05-acceptance.md) — критерии приёмки продукта.

## Что не входит в обязательное чтение

Материалы за пределами `handoff/` не нужны для понимания задачи разработчиком.
