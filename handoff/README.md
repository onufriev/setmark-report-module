# Передача в разработку

Handoff собирается после проверки рабочего прототипа либо при явно зарегистрированном решении Product Manager `SKIPPED_BY_PM`. В последнем случае комплект должен содержать визуальный прототип и это решение; рабочая реализация не заявляется как проверенная.

Минимальный комплект:

- baseline подтверждённых требований и трассировка;
- рабочий прототип и `prototype/PROTOTYPE-RUNBOOK.md`;
- выбранный стек и перечень конфигурации;
- источник данных, команды наполнения, проверки, сброса и очистки;
- критерии приёмки, ограничения и известные отличия от production;
- ссылки на отчёты из `reports/` и доказательства `ART-EV-*`;
- открытые неблокирующие вопросы и принятые временные решения.

Для завершения `HANDOFF_READY` каталог должен содержать фактические материалы передачи, после чего он регистрируется через `tools/register_artifact_evidence.py`. Один `README.md` доказательством handoff не является.
