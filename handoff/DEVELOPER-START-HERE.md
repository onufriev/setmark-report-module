# Set Mark: мониторинг и анализ нарушений

## Что нужно сделать

Реализовать MVP модуля мониторинга и анализа нарушений Set Mark по требованиям из пяти файлов в [requirements](requirements/). Это самостоятельная выжимка требований: не нужно искать базовую версию требований или читать служебные решения.

## Важные рамки реализации

- MVP применяется для организаций с установленной страной `RU`; остальные разделы Set Mark не должны быть нарушены.
- Конкретный технологический стек, производственная архитектура, API-контракты и источник производственных данных выбираются и фиксируются командой разработки.

## Результат

Реализация должна удовлетворять требованиям, сценариям и критериям приёмки из этого каталога и сохранять поведение существующей платформы Set Mark вне описанного MVP.
