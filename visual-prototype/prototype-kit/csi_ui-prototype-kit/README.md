# csi_ui-prototype-kit

Переиспользуемый визуальный kit для HTML/CSS/JS-прототипов, собранный по `CSI_UI` v1.31.2.

Это базовый визуальный слой для `visual-prototype`. Он не заменяет React-компоненты CSI UI: автономная копия React/Storybook находится в `visual-prototype-storybook/`.

## Назначение

Kit фиксирует визуальные правила Storybook/CSI UI без зависимости прототипа от React или запущенного Storybook. Проектный прототип подключает `csi-ui.css`, а свои экраны и данные держит отдельно.

## Состав

- `tokens.css` — значения `lightTheme` CSI UI;
- `csi-ui.css` — базовые стили, состояния и layout-примитивы для HTML-прототипов;
- `icons.css` — семантические классы иконок для временной HTML-реализации;
- `source-manifest.json` — версия и исходные файлы CSI UI, использованные при сборке.

## Обновление

При обновлении `CSI_UI` нужно пересобрать эту папку из новой версии Storybook и исходников темы. Проектные прототипы не должны изменять файлы kit локальными правилами: используйте `prototype-overrides.css` внутри конкретного прототипа.
