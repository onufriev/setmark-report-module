# Визуальный прототип

Создаётся только после утверждения PRODUCT_DEFINITION и актуального baseline требований.

Обязательны:

- локальная реализация, а не только ссылка или макет;
- `prototype-manifest.json` со статусом `READY`;
- заполненный `PROTOTYPE-RUNBOOK.md`;
- точка входа и способ запуска;
- источник демонстрационных данных;
- успешная проверка `tools/validate_visual_prototype.py` и `ART-EV-*`.
