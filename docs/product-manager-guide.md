# Руководство Product Manager

Product Manager:

1. указывает источники;
2. отвечает на один вопрос за раз;
3. явно подтверждает требования или их неприменимость;
4. выбирает источник UI;
5. перед рабочим прототипом выбирает стек и источник данных;
6. просматривает PDF-отчёт и отдельным сообщением разрешает переход.

Product Manager не обязан редактировать JSON, запускать инструменты или самостоятельно искать пропущенные области. Если область неизвестна, Product Compiler обязан показать `NEEDS_INPUT`, а не оставить её пустой.

Проверка доверия:

- у подтверждённого требования есть `SRC-EV-*` или `PM-DEC-*`;
- `product/completeness-report.json` показывает `PASSED` для нужного gate;
- `product/requirements-baseline.json` имеет статус `COMMITTED`;
- прототип содержит инструкцию запуска и доказательство `ART-EV-*`.
