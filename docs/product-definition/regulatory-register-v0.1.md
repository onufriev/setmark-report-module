# Нормативный реестр v0.1

**Продукт:** модуль контроля нарушений Set Mark  
**Версия:** 0.1  
**Дата проверки источников:** 2026-07-28  
**Статус:** рабочий проект для Product Definition и юридической проверки  
**Связанные артефакты:** [Каталог инцидентов v0.1](incident-catalog-v0.1.md), [Decision Model v0.1](decision-model-v0.1.md)

## 1. Назначение и границы

Реестр разделяет два разных правовых механизма:

1. **Автоматическое привлечение к административной ответственности** — постановление и штраф по конкретному составу КоАП РФ на основании данных ГИС МТ.
2. **Индикатор риска** — агрегированный сигнал для назначения внепланового контрольного (надзорного) мероприятия. Превышение индикатора само по себе не является штрафом и не превращает отдельную продажу в «допустимую» или «недопустимую».

В реестр включены только правила, связанные с розничной реализацией и выбытием маркированных товаров. Индикаторы остатков, длительности хранения и сравнительно низкого оборота исключены из исполнимой области Set Mark, потому что не формируются отдельными операциями выбытия.

Это продуктовый нормативный реестр, а не юридическое заключение. Продукт не утверждает факт назначения штрафа: он показывает наличие или отсутствие подтверждённого риска по зафиксированным условиям нормы.

## 2. Статусы правил

| Статус | Значение для продукта |
|---|---|
| Действует | Разрешено использовать в расчёте нормативной критичности с учётом даты операции или расчётного месяца |
| Принято, не вступило в силу | Хранить как будущую норму; до даты вступления показывать только прогнозно |
| Проект | Не использовать как действующее правило; допускается отдельный прогнозный расчёт |
| Требует юридической проверки | Недостаточно данных для пользовательского утверждения о правовом последствии |

### 3.1. Продуктовое правило AF-001

`potentialAutoFineRisk = true` допустимо только при одновременном подтверждении:

- кассовая операция состоялась не ранее 2026-09-01;
- товар и операция входят в область действия части 4 статьи 14.43 КоАП РФ;
- срок годности истёк к моменту продажи;
- онлайн ЧЗ передал запрет продажи именно по этой проверке;
- продажа завершена несмотря на запрет.

Если онлайн ЧЗ был недоступен, а ЛМ ЧЗ разрешил продажу, условие «получена информация о запрете из ГИС МТ» не подтверждено. Для такого инцидента риск по AF-001 равен «Нет», но инцидент может участвовать в действующем индикаторе риска продажи просроченной продукции.

## 6. Правило расчёта агрегата

Для каждого нормативного правила `NR-xxx`, магазина, товарной группы и календарного месяца:

```text
numerator = количество единиц реализации, удовлетворяющих условиям индикатора
denominator = опубликованный/полученный из ГИС МТ средний объём реализации
              этой товарной группы в одном объекте РФ за тот же месяц
sharePercent = numerator / denominator * 100
thresholdExceeded = sharePercent > thresholdPercent
```

Граница является строгой: формулировка «более N%» означает `sharePercent > N`, а не `>= N`.

Если знаменатель не получен из подтверждённого внешнего источника:

- Set Mark показывает локальный числитель, количество и динамику инцидентов;
- точное состояние «ниже порога / порог превышен» не вычисляется;
- нельзя подменять национальный средний объём собственным оборотом магазина;
- состояние агрегата — «Не оценён: отсутствует нормативный знаменатель».

## 7. Требования к данным и версии результата

Каждый нормативный результат должен хранить:

- ID и версию нормативного правила;
- статус нормы на дату расчёта;
- дату кассовой операции для автоштрафа либо календарный месяц для индикатора;
- товарную группу;
- объект розничной торговли и, где требуется, ККТ;
- числитель, знаменатель, процент и источник знаменателя;
- признак наличия запроса в ГИС МТ перед продажей;
- источник решения: онлайн ЧЗ / ЛМ ЧЗ / нет подтверждения;
- применённую статью КоАП или пункт приказа;
- дату и время расчёта.

Автоматическая переклассификация существующих инцидентов не выполняется. Новая версия нормы применяется только к инцидентам и агрегатам, созданным после её активации, если отдельным решением не утверждён пересчёт.
