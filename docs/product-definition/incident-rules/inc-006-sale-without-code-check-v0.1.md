# Правило анализа INC-006 v0.1

**Инцидент:** Продажа товара без проверки КМ  
**Код True API:** категория `12`, вид `30`, результат `48`  
**Статус:** согласовано Product Manager  
**Дата решения:** 2026-07-31  
**Связанные артефакты:** [Каталог инцидентов v0.1](../incident-catalog-v0.1.md), [Модель необходимых действий v0.1](../necessary-action-model-v0.1.md), [Схема анализа INC-006](../diagrams/inc-006-analysis-flow-v0.1.svg)

## 1. Назначение

Правило определяет анализ отклонения Честного Знака «Продажа товара без проверки КМ» и необходимые действия по доступным данным Set Mark и SetRetail.

Суть отклонения: в фискальном чеке в данных позиции проданного маркированного товара отсутствует квитанция ответа как от онлайн-сервиса Честного Знака, так и от ЛМ ЧЗ.

Само отклонение не доказывает, что касса вообще не обращалась к сервисам проверки. Возможны как отсутствие проверки, так и потеря результата при формировании или передаче чека. В версии v0.1 Set Mark не получает кассовые логи обращений к онлайн ЧЗ и ЛМ ЧЗ и не проверяет чек в ОФД.

## 2. Необходимые данные

Для анализа используются:

- код маркировки;
- дата и время продажи;
- идентификатор кассового чека;
- данные позиции маркированного товара в чеке SetRetail;
- наличие квитанции проверки КМ в данных позиции;
- источник квитанции: онлайн ЧЗ или ЛМ ЧЗ, если он указан;
- товарная группа;
- текущая конфигурация процессинга `Валидация в сервисе Честный знак`;
- значение настройки `Разрешить продажу при отсутствии ответа от ЧЗ`.

В v0.1 не используются:

- логи обращений кассы к онлайн ЧЗ и ЛМ ЧЗ;
- автоматическая проверка чека в личном кабинете ОФД;
- историческая конфигурация магазина, если она отдельно не сохранена.

Текущая конфигурация не доказывает, что те же значения действовали в момент продажи.

## 3. Общая классификация

Для этого типа отклонения:

- риск автоштрафа: **нет**;
- критичность отдельного инцидента в модели Set Mark: **некритическое**;
- инцидент может участвовать в расчёте накопленного регуляторного риска, если для товарной группы действует соответствующий индикатор риска.

## 4. Первая проверка: квитанция в нашем кассовом чеке

Set Mark находит соответствующий кассовый чек SetRetail и проверяет данные позиции маркированного товара.

### 4.1. Квитанция отсутствует

Если в данных позиции нет квитанции ни онлайн ЧЗ, ни ЛМ ЧЗ, система устанавливает:

- результат: подтверждённое нарушение;
- критичность: некритическое;
- риск автоштрафа: нет;
- объяснение: продажа завершена без зафиксированной в нашем кассовом чеке квитанции обязательной проверки КМ.

По доступным данным нельзя достоверно установить, не выполнялась ли проверка либо её результат не был записан в чек.

Далее система проверяет текущую конфигурацию магазина.

### 4.2. Квитанция присутствует

Если в данных позиции есть квитанция онлайн ЧЗ или ЛМ ЧЗ, система устанавливает:

- по данным SetRetail проверка КМ была выполнена и её результат сохранён;
- нарушение ритейлера по доступным данным не подтверждено;
- причина расхождения с отклонением Честного Знака не определена достоверно.

Необходимое действие:

> Обратиться в техническую поддержку Честного Знака и приложить сведения об отклонении, кассовом чеке, коде маркировки и сохранённой квитанции проверки.

Set Mark v0.1 не выполняет дополнительную проверку чека в ОФД.

## 5. Анализ причины при отсутствии квитанции

### 5.1. Причина 1: отключена проверка товарной группы

Проверяется процессинг:

`Интеграция → Внешние процессинги → Валидация в сервисе Честный знак`

Для соответствующей товарной группы должен быть включён параметр `Валидировать…`.

Если проверка товарной группы отключена, наиболее вероятная причина по текущей конфигурации:

> Для товарной группы была отключена обязательная проверка в Честном Знаке, поэтому касса могла сформировать продажу без квитанции проверки КМ.

Необходимое действие:

> Включить валидацию соответствующей товарной группы.

### 5.2. Причина 2: разрешена продажа при отсутствии ответа

Проверяется настройка:

`Разрешить продажу при отсутствии ответа от ЧЗ`

Если настройка включена, наиболее вероятная причина по текущей конфигурации:

> Кассовая конфигурация разрешала завершить продажу маркированного товара при отсутствии ответа от сервисов проверки. В результате в чеке могла отсутствовать квитанция онлайн ЧЗ или ЛМ ЧЗ.

Необходимое действие:

> Отключить настройку `Разрешить продажу при отсутствии ответа от ЧЗ`.

Отдельная проверка наличия или настройки ЛМ ЧЗ в данном правиле не выполняется. Для определения причины важно именно то, могла ли касса завершить продажу без полученного ответа.

### 5.3. Все проверяемые настройки корректны

Если:

- проверка товарной группы включена;
- `Разрешить продажу при отсутствии ответа от ЧЗ` выключена;
- но квитанция в нашем чеке отсутствует,

система фиксирует:

- статус причины: `Причина не определена достоверно`;
- результат: подтверждённое некритическое нарушение;
- необходимое действие: обратиться в техническую поддержку CSI для проверки формирования реквизитов маркированного товара и квитанции разрешительной проверки в кассовом чеке.

## 6. Порядок проверок

```text
Получено отклонение INC-006
        ↓
Проверить наш кассовый чек
        ├─ Квитанция есть
        │      ↓
        │  Нарушение ритейлера не подтверждено
        │  → обратиться в поддержку Честного Знака
        │
        └─ Квитанции нет
               ↓
           Нарушение подтверждено
           Риск автоштрафа: нет
               ↓
           Включена проверка товарной группы?
               ├─ Нет → включить валидацию товарной группы
               └─ Да
                      ↓
                  Разрешена продажа при отсутствии ответа от ЧЗ?
                      ├─ Да → отключить настройку
                      └─ Нет → причина не определена достоверно
                               → обратиться в поддержку CSI
```

## 7. Ограничения правила v0.1

- Set Mark не получает кассовые логи обращений к онлайн ЧЗ и ЛМ ЧЗ.
- Set Mark не проверяет чек в ОФД.
- Наличие текущего отклонения настройки показывает возможную причину, но не доказывает историческую конфигурацию в момент продажи.
- Отдельная настройка или доступность ЛМ ЧЗ не проверяется в качестве самостоятельной причины.
- Правило не относит данный тип отклонения к основаниям автоштрафа.
- При изменении правила новые условия применяются только к новым инцидентам, если отдельно не принято решение о пересчёте.
