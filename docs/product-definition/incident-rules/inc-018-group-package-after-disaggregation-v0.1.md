# Правило анализа INC-018 v0.1

**Инцидент:** Продажа кода групповой упаковки после выбытия
**Код True API:** категория `8`, вид `20`, результат `29`
**Статус:** согласовано Product Manager
**Основание согласования:** `PM-DEC-067`
**Связанные артефакты:** [Каталог инцидентов v0.1](../incident-catalog-v0.1.md), [Правило INC-001](inc-001-repeat-sales-same-seller-v0.1.md), [Схема анализа INC-018](../diagrams/inc-018-analysis-flow-v0.1.svg)

## 1. Назначение

INC-018 применяется, когда после выбытия групповой упаковки продан её групповой код. Групповая упаковка может выбыть не только при продаже самого группового кода, но и при продаже хотя бы одного входящего КМ: такая операция расформировывает упаковку.

## 2. Необходимые данные

- групповой код упаковки, магазин, касса и чек;
- количество продаж группового кода в SMC;
- возвраты группового кода между продажами;
- состав групповой упаковки: перечень входящих КМ, если он загружен в SMC;
- продажи входящих КМ до продажи группового кода;
- отклонение и сведения Честного Знака о предыдущем выбытии.

## 3. Возможные причины и действия

| Условие | Результат | Причина / статус причины | Необходимое действие |
|---|---|---|---|
| В SMC найдены две продажи группового кода | Применить INC-001 | Возможна обычная повторная продажа | Продолжить анализ по INC-001 с проверкой возврата и блокировки повторной продажи |
| В SMC одна продажа группового кода; состав упаковки известен; до неё продан входящий КМ | `RA-01` | Упаковка была расформирована продажей входящего КМ, после чего продан недействующий групповой код | Скорректировать бизнес-процесс: не продавать групповой код после выбытия любого входящего КМ |
| В SMC одна продажа группового кода; состав упаковки в SMC отсутствует | `RA-04` | SMC не располагает данными, позволяющими проверить предыдущее расформирование | Загружать групповые упаковки в SMC с указанием входящих КМ; по данным Честного Знака установить предыдущее выбытие |
| В SMC одна продажа; состав известен; продаж входящих КМ до неё не найдено | `RA-04` | Локальные данные противоречат отклонению либо неполны | Обратиться в поддержку Честного Знака с групповым кодом, чеком и составом упаковки |
| Продажа группового кода в SMC не найдена | `RA-04` | Не удалось сопоставить отклонение с локальной операцией | Получить полный групповой код, чек и историю операций |

## 4. Ограничения v0.1

- Без состава групповой упаковки SMC не может достоверно установить продажу входящего КМ как причину расформирования.
- Наличие одной продажи группового кода не исключает более раннюю продажу входящего КМ.
- Загрузка состава упаковок является мерой обеспечения данных для контроля, а не доказательством причины уже произошедшего инцидента.
- Если найдены две продажи группового кода, отдельный алгоритм групповой упаковки не подменяет правило повторной продажи INC-001.
- Риск автоштрафа устанавливается в `Нет`, пока отдельное действующее нормативное правило не подтверждено.

## 5. Критерии приёмки

1. Две продажи группового кода маршрутизируются в INC-001.
2. При одной продаже система проверяет предшествующие продажи входящих КМ, если состав упаковки известен.
3. Продажа входящего КМ до продажи группового кода подтверждает расформирование упаковки.
4. При отсутствии состава система не объявляет причину установленной и рекомендует загрузить состав упаковок в SMC.
5. При отсутствии локальных подтверждений система применяет `RA-04`.
