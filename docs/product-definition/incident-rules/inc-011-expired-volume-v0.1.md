# Правило анализа INC-011 v0.1

**Инцидент:** Реализация товаров с истекшим сроком годности в объёмных показателях
**Код True API:** категория `13`, вид `32`, результат `50`
**Статус:** согласовано Product Manager
**Основание согласования:** `PM-DEC-058`
**Связанные артефакты:** [Правило INC-002](inc-002-expired-product-sale-v0.1.md), [Каталог инцидентов v0.1](../incident-catalog-v0.1.md), [Схема анализа INC-011](../diagrams/inc-011-analysis-flow-v0.1.png)

## 1. Назначение

INC-011 выделяется отдельно из-за частичного выбытия товара в объёмных показателях, но срок годности анализируется по тем же правилам, что в INC-002. Вскрытие тары и возможное изменение срока после вскрытия происходят вне кассового контура и не образуют отдельной ветки анализа Set Mark.

## 2. Необходимые данные

- КМ, товарная группа, чек, объём реализации и факт продажи;
- канал и полный результат проверки;
- `expireDate` из онлайн-ответа, если он получен;
- результат разбора `expireDate` кассой;
- доказательства использования ЛМ ЧЗ либо отсутствия результата обоих каналов.

## 3. Возможные причины и действия

| Условие | Результат | Причина / статус причины | Необходимое действие |
|---|---|---|---|
| Онлайн-ответ содержит успешно распознанный `expireDate`; срок на момент продажи истёк; продажа завершена | `RA-01` | Штатная проверка должна была заблокировать продажу; отдельной настройки игнорирования корректно распознанного истёкшего срока нет | Обратиться в поддержку CSI с чеком, КМ и полным онлайн-ответом |
| Онлайн ЧЗ недоступен; ЛМ ЧЗ дал разрешающий результат; продажа завершена | `RA-01`; риск автоштрафа `Нет` | Законный офлайн-режим не возвращает `expireDate` и не мог проверить срок годности | Кассовое исправление не требуется; отразить ограничение офлайн-проверки |
| Доказано отсутствие результата обоих каналов; продажа завершена | `RA-01` | Продажа прошла без результата обязательной проверки | Проверить валидацию соответствующей товарной группы в ЧЗ; при корректной настройке обратиться в CSI |
| Исторический результат проверки не найден либо данные противоречивы | `RA-04` | Причина не определена достоверно | Получить кассовые логи и полный результат выбранного канала |

## 4. Ограничения v0.1

- Для отсутствующего, пустого или неразбираемого `expireDate` применяется соответствующая ветка подробного правила INC-002.
- Настройки игнорирования корректно распознанного истёкшего срока нет.
- Технический алгоритм срока годности не зависит от того, вскрывалась ли тара вне кассовой системы.
