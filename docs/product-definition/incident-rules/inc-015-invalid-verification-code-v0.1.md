# Правило анализа INC-015 v0.1

**Инцидент:** Продажа товара с некорректным кодом проверки
**Код True API:** категория `12`, вид `29`, результат `44`
**Статус:** согласовано Product Manager
**Основание согласования:** `PM-DEC-062`
**Связанные артефакты:** [Каталог инцидентов v0.1](../incident-catalog-v0.1.md), [Decision Model v0.1](../decision-model-v0.1.md), [Схема анализа INC-015](../diagrams/inc-015-analysis-flow-v0.1.png), [Единая ветка доказанного отсутствия результата](../diagrams/proven-no-response-settings-flow-v0.1.svg)

## 1. Назначение

Правило анализирует поле `valid` онлайн-ответа. `valid=false` означает некорректный код проверки и должно блокировать продажу, если касса не настроена игнорировать этот признак. ЛМ ЧЗ не проверяет `valid`.

## 2. Необходимые данные

- КМ, товарная группа, чек и факт продажи;
- сохранённый онлайн-ответ и значение `valid`;
- подтверждение использования ЛМ ЧЗ, если онлайн-ответа не было;
- текущая настройка `check.excise.ignoreTrueApiMarkVerified`;
- текущая настройка валидации товарной группы;
- текущая настройка `Разрешить продажу при отсутствии ответа от ЧЗ`;
- доказательства попыток проверки, если результата не было.

## 3. Возможные причины и действия

| Условие | Результат | Причина / статус причины | Необходимое действие |
|---|---|---|---|
| Онлайн ЧЗ ответил `valid=false`; продажа завершена; `check.excise.ignoreTrueApiMarkVerified=true` | `RA-01` | Игнорирование позволило завершить продажу при отрицательном признаке | Установить `check.excise.ignoreTrueApiMarkVerified=false` |
| Онлайн ЧЗ ответил `valid=false`; продажа завершена; игнорирование уже выключено | `RA-01` | Обязательная блокировка не сработала | Обратиться в поддержку CSI; передать чек, КМ и полный онлайн-ответ |
| Онлайн ЧЗ ответил `valid=true`, но позднее получен INC-015 | `RA-04` | Сохранённый ответ противоречит отклонению | Обратиться в поддержку Честного Знака с полным ответом и отклонением |
| Онлайн ЧЗ недоступен; ЛМ ЧЗ дал разрешающий результат; продажа завершена | `RA-01`; риск автоштрафа `Нет` | Законный fallback не проверяет `valid` и не мог выявить нарушение | Кассовое исправление не требуется; отразить ограничение ЛМ ЧЗ |
| Доказано отсутствие результата обоих каналов; продажа завершена | `RA-01` | Продажа прошла без результата обязательной проверки; возможные факторы — отключённая валидация товарной группы либо разрешённая продажа при отсутствии ответа; если обе настройки корректны, причина не определена достоверно | Проверить и включить валидацию товарной группы. Если она включена, проверить настройку `Разрешить продажу при отсутствии ответа от ЧЗ` и отключить разрешение. Если обе настройки уже корректны, обратиться в CSI |
| Исторический результат не найден либо канал не установлен | `RA-04` | Причина не определена достоверно | Получить кассовые логи, полный онлайн-ответ и реквизиты офлайн-квитанции |

## 4. Ограничения v0.1

- Текущая настройка является возможным фактором, но не доказательством исторической конфигурации.
- ЛМ ЧЗ не возвращает результат проверки `valid`.
- Значение `found` относится к INC-003 и не подменяет `valid`.
