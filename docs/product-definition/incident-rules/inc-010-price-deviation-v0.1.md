# Правило анализа INC-010 v0.1

**Инцидент:** Продажа с нарушением МЦ / МРЦ / ЕМЦ
**Коды True API:** категория `1`; виды `1`, `2`, `5`, `12`, `13`, `35`, `48`; результаты `1`, `2`, `5`, `16`, `17`, `55`, `69`
**Статус:** согласовано Product Manager
**Основание согласования:** `PM-DEC-057`
**Связанные артефакты:** [Каталог инцидентов v0.1](../incident-catalog-v0.1.md), [Decision Model v0.1](../decision-model-v0.1.md), [Схема анализа INC-010](../diagrams/inc-010-analysis-flow-v0.1.png), [Единая ветка доказанного отсутствия результата](../diagrams/proven-no-response-settings-flow-v0.1.svg)

## 1. Назначение

Правило объединяет ценовые отклонения, для которых касса должна сопоставить цену продажи с применимыми значениями МЦ, МРЦ или ЕМЦ из результата обязательной проверки. Онлайн ЧЗ и ЛМ ЧЗ являются источниками исходных данных; итоговое решение о допустимости продажи формирует кассовое ПО.

Отдельной настройки, позволяющей игнорировать полученное применимое ценовое ограничение, нет.

## 2. Необходимые данные

- КМ, товарная группа, чек, цена и факт завершения продажи;
- точный код и название отклонения True API;
- использованный канал проверки;
- полный сохранённый результат и применимое значение МЦ, МРЦ или ЕМЦ;
- события решения кассового ПО;
- доказательства попыток онлайн- и офлайн-проверки, если результата не было;
- текущая настройка валидации товарной группы в ЧЗ.
- текущая настройка `Разрешить продажу при отсутствии ответа от ЧЗ`.

## 3. Возможные причины и действия

| Условие | Результат | Причина / статус причины | Необходимое действие |
|---|---|---|---|
| Сохранён результат онлайн ЧЗ или ЛМ ЧЗ с применимым ценовым ограничением; цена ему не соответствует; продажа завершена | `RA-01` | Кассовое ПО не применило обязательное ценовое ограничение; настройки игнорирования нет | Обратиться в поддержку CSI; передать чек, КМ, канал, полный результат проверки, цену продажи и применимое ограничение |
| Сохранённый результат содержит данные, при которых цена продажи не образует полученное отклонение | `RA-04` | Данные противоречат отклонению | Передать отклонение, чек и полный результат проверки в поддержку Честного Знака |
| Доказано, что результата не было ни от онлайн ЧЗ, ни от ЛМ ЧЗ, но продажа завершена | `RA-01` | Продажа прошла без результата обязательной проверки; возможные факторы — отключённая валидация товарной группы либо разрешённая продажа при отсутствии ответа; если обе настройки корректны, причина не определена достоверно | Проверить и включить валидацию товарной группы. Если она включена, проверить настройку `Разрешить продажу при отсутствии ответа от ЧЗ` и отключить разрешение. Если обе настройки уже корректны, обратиться в CSI |
| Исторический результат только отсутствует в доступной выборке или не найден | `RA-04` | Отсутствие сохранённого результата не доказывает отсутствие проверки | Получить кассовые логи, события решения и ответы онлайн ЧЗ / ЛМ ЧЗ |

## 4. Ограничения v0.1

- Правило не включает отклонение «Оборот ниже минимальной цены (НСП)» (`вид 47`, `результат 61`), пока оно не разобрано отдельно.
- Текущая настройка валидации не доказывает её историческое значение на момент продажи.
- Риск автоштрафа определяется только отдельным применимым нормативным правилом.
- Формулировка «ЧЗ запретил продажу» не используется: ЧЗ возвращает данные, а кассовое ПО применяет правило.
