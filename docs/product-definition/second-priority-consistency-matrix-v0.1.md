**Статус:** проверено перед PR
**Основания:** `PM-DEC-065`–`PM-DEC-068`
**Связанные артефакты:** [Каталог инцидентов](incident-catalog-v0.1.md), [Правила анализа](incident-rules/README.md)

## 1. Матрица

## 2. Проверенные инварианты

1. Исторический результат, который просто не найден, не считается доказанным отсутствием проверки.
2. Исходные признаки Честного Знака отделены от решения кассового ПО и факта продажи.
3. Для INC-017 соблюдается порядок `sold=true` → табачное исключение `grayZone=true` → `realizable=false`.
4. `ogvs` используется только при `isBlocked=true`; `VETRF` уточняет источник, но не создаёт новый кассовый алгоритм.
5. Настройки указаны только там, где их существование подтверждено текущими правилами репозитория.
6. Схема, подробное правило, строка каталога и официальное сопоставление кодов описывают одинаковые ветки.
7. Статус «Согласовано Product Manager» имеет зарегистрированное основание `PM-DEC-*`.
