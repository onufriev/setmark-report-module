Критическое

Риск автоштрафа: Да

Причина не определена достоверно

Штатная проверка срока годности должна была заблокировать продажу.

Необходимое действие: обратиться в техническую поддержку CSI.

НЕТ

Подтверждённое нарушение

Критическое

Риск автоштрафа: Да

Причина

Настройка разрешила продолжить продажу при некорректном сроке годности.

Необходимое действие: запретить продажу при отсутствующем, пустом, null или неразбираемом expireDate.

check.excise.ignoreTrueApiMarkIncorrectExpirationDate = false

НЕТ — онлайн ЧЗ недоступен, использован ЛМ ЧЗ

ЛМ ЧЗ не возвращает expireDate

↓

Подтверждённое нарушение

Некритическое

Риск автоштрафа: Нет

Причина

Использование ЛМ ЧЗ позволило выполнить продажу без данных о сроке годности.

Необходимое действие: для полного исключения риска можно отключить ЛМ ЧЗ и проверять маркированные товары только через онлайн «Честный знак».

Важно: после отключения ЛМ ЧЗ при недоступности онлайн «Честного знака» продажа маркированных товаров будет заблокирована.
Схема онлайн → ЛМ ЧЗ является штатным fallback. Отключение ЛМ ЧЗ — усиленная бизнес-мера для полного исключения риска продажи просроченного товара, а не обязательное исправление для каждого LM-сценария.
