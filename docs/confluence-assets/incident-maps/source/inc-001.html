Проверяемая конфигурация Set Mark

  • Флаги «Валидировать товарную категорию» для соответствующего типа товара.
  • Параметры продажи при недоступности сервера.

НЕТ — возврата нет

Результат анализа

Вторая продажа считается подтверждённым нарушением.

1

Продажи выполнены в разных магазинах?

Если да — проверить архитектуру Set Mark. При отдельных экземплярах Set Mark Centrum в магазинах возможная причина — локальный экземпляр не располагал сведениями о продаже в другом магазине.

Необходимое действие: перейти на централизованный Set Mark Centrum.

2

Проверить настройки товарной категории в Set Mark

По товару определяется product_type, затем проверяется соответствующий флаг валидации.

Если нужный флаг выключен — возможная причина.

Необходимое действие: включить валидацию соответствующей категории.

3

Проверить продажу при недоступности Set Mark

Проверяются параметры, разрешающие операцию при недоступности сервера, включая отдельный параметр для акцизного алкоголя.

Если продажа прошла при недоступности и была разрешена настройкой — возможная причина.

Необходимое действие: запретить продажу маркированных товаров при недоступности Set Mark.

4

Проверить диагностические данные

Параметр «Сохранять результат проверки сведений о товаре в журнале нарушений» нужен для полноты диагностики, но сам по себе не является причиной повторной продажи.

5

Ни одна известная причина не подтверждена

Причина не определена достоверно.

Необходимое действие: обратиться в техническую поддержку CSI.

Важно: конфигурация показывает текущее состояние на момент анализа. Без истории версий она не доказывает, что те же значения действовали во время продажи.
