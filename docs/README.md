# Вспомогательная документация

Каталог `docs/` содержит человекочитаемые материалы, которые объясняют продукт,
процесс работы и принятые решения:

- руководства для Product Manager и команды разработки;
- аналитические и предметные модели;
- подробные пояснения и диаграммы;
- презентационные материалы.

`docs/`, включая `docs/product-definition/`, не является источником базовых или
канонических требований. Единственный канонический источник обязательных требований
— каталог `requirements/`. Итоговый `handoff/` является их производным
человекочитаемым представлением для архитектора, лида и разработчика.

Product Manager, аналитики, архитекторы и разработчики могут использовать `docs/`
для контекста. Если документ содержит обязательное правило, оно должно быть
представлено подтверждённым требованием в `requirements/`. При противоречии действует
`requirements/`, а расхождение регистрируется и передаётся Product Manager для
решения.

Устаревший или дублирующий документ необходимо явно пометить как исторический либо
перенести в `reference-materials/`.
