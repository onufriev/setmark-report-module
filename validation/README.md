# Проверка продукта и прототипов

Папка предназначена для материалов клиентской и пользовательской проверки: сценариев сессии, наблюдений, результатов и решений по итогам проверки.

Каждая проверка должна содержать:

1. цель и проверяемую гипотезу;
2. ссылку на baseline требований и ревизию прототипа;
3. роли и условия проведения;
4. сценарии и ожидаемые сигналы успеха;
5. фактические результаты и найденные ограничения;
6. решение Product Manager: принять, доработать или остановить направление.

Результаты проверки не заменяют требования. Изменения требований после проверки регистрируются как новые evidence, вносятся в `requirements/` и фиксируются новым baseline.
