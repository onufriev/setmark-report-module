# Claude Desktop / Cowork

Эта папка содержит инструкции для запуска Product Compiler в Claude Desktop.

## Подключение

1. Откройте проект или рабочую папку `product compiler`.
2. Используйте `PROJECT-INSTRUCTIONS.md` как инструкции проекта, если среда не читает корневой `CLAUDE.md` автоматически.
3. Дайте Claude доступ к файлам проекта.

## Критики из коробки

- Claude Code и совместимые репозиторные сессии обнаруживают project skills из `.claude/skills/`.
- В средах, где project skills не загружаются, Claude использует те же инструкции из `critics/agents/`.
- Перед запуском критика Claude обязан спросить согласие Product Manager.
- Прямой запрос конкретного критика считается согласием.
- Отчёты сохраняются в `critics/reports/`.

Таким образом, папка `codex/` не требуется Claude и не мешает его работе: Codex и Claude используют разные адаптеры, а общий источник поведения критиков хранится в `critics/agents/`.
