# Claude Desktop

Создайте Claude Project, вставьте содержимое `PROJECT-INSTRUCTIONS.md` в инструкции проекта и загрузите как минимум:

- `PRODUCT-COMPILER.md`;
- `internal/domain-catalog.json`;
- `requirements/README.md`;
- `tools/README.md`;
- актуальные исходные материалы.

Для полноценной работы нужен файловый MCP/extension с доступом к корню проекта и возможностью запускать Python-инструменты. Без выполнения `tools/` Claude Desktop может анализировать материалы, но не способен надёжно:

- зарегистрировать evidence и решения;
- построить индекс и проверить полноту;
- зафиксировать baseline требований;
- проверить прототип и его runbook;
- атомарно зарегистрировать отчёт и изменить этап.

При отсутствии файлового доступа используйте проект только как аналитический шаблон и не считайте переходы этапов подтверждёнными.
