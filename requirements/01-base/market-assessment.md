# Экспресс-оценка рынка Set Mark

## REQ-MKT-001. Область и назначение оценки

**Область:** salesObjects
**Статус:** Подтверждено Product Manager
**Основание:** PM-DEC-095, PM-DEC-096
**Применимость:** Product discovery
**Дата среза:** 2026-09-01

Оценка определяет потенциальный новый валовый годовой доход от допродажи лицензий Set Mark действующим клиентам с кассовыми лицензиями SetRetail. Она используется для проверки коммерческого потенциала продукта и не является утверждённым прайс-листом или прогнозом продаж.

В расчёт включаются только рабочие клиенты с подтверждённой страной `RU`, активной кассовой лицензией и положительным значением поля «Используемое количество». Тестовые контуры, клиенты других стран, лицензии с истёкшим сроком и клиенты без подтверждённой страны исключаются.

## REQ-MKT-002. Источники и правила сопоставления

**Область:** salesObjects
**Статус:** Подтверждено Product Manager
**Основание:** PM-DEC-095
**Применимость:** Product discovery

Использованы три предоставленных среза:

- `Клиенты с кассовой лицензией.xlsx` — кассовые лицензии и количество используемых касс;
- `Текущие клиенты SetMark.xlsx` — типы лицензий Set Mark и количество использующих их магазинов;
- `Клиенты по странам.xlsx` — страна клиента.

Кассовые лицензии и лицензии Set Mark сопоставляются по точному `Set ID`. Страна присоединяется по точному совпадению названия клиента, поскольку файл стран не содержит `Set ID`. Клиенты, для которых такое сопоставление не выполнено, не считаются клиентами `RU` и не входят в денежную оценку.

После очистки получено:

- 515 активных производственных RU-клиентов с используемыми кассами;
- 92 из них уже имеют активную лицензию Set Mark;
- 423 клиента составляют новый адресный пул;
- текущее проникновение Set Mark в очищенной базе — `92 / 515 = 17,9%`;
- потенциал роста по числу новых клиентов — 423 сети, или 82,1% очищенной базы.

## REQ-MKT-003. Пересчёт касс в магазины

**Область:** salesObjects
**Статус:** Подтверждено Product Manager
**Основание:** PM-DEC-095
**Применимость:** Product discovery

Первичный файл содержит количество касс, тогда как Set Mark лицензируется на магазин. Для пересчёта используется медианное фактическое отношение используемых касс к использующим Set Mark магазинам у действующих RU-клиентов, присутствующих в обоих лицензионных срезах.

- размер пригодной выборки: 73 клиента;
- медианное отношение: 4,23 кассы на магазин;
- расчёт для каждой сети: `max(1; округление вверх(используемые кассы / 4,23))`;
- в новом адресном пуле: 25 070 используемых касс;
- оценочное количество магазинов: 6 143.

Медиана выбрана вместо среднего из-за значительных выбросов и неполной активации лицензий в отдельных сетях. Оценка должна пересчитываться при появлении прямого реестра магазинов потенциальных клиентов.

## REQ-MKT-004. Коммерческие допущения

**Область:** salesObjects
**Статус:** Подтверждено Product Manager
**Основание:** PM-DEC-095, PM-DEC-096
**Применимость:** Product discovery

- Set Mark продаётся отдельно по каждому типу лицензии.
- Оценочная цена одного типа лицензии — 4 000 рублей с НДС за магазин в год.
- Если сеть принимает решение о покупке, лицензия распространяется на 100% её оценочных магазинов.
- Вероятность покупки для каждой новой сети — 80%.
- Считается валовый доход без скидок, партнёрских условий, бесплатных лицензий и стоимости внедрения.
- Учитывается только новый доход; существующие клиенты Set Mark и их текущие лицензии из денежного потенциала исключены.

Поскольку в данных нет товарного профиля потенциальных клиентов, распределение типов оценивается по фактическому количеству используемых лицензий у активных RU-клиентов Set Mark:

- «Продовольственные товары» — 3 625 лицензий, или 33,2% количества трёх основных типов;
- «Непродовольственные товары» — 3 206 лицензий, или 29,3%;
- `Alco` — 4 098 лицензий, или 37,5%.

Для учёта того, что один магазин может использовать несколько типов, по каждому текущему клиенту количество магазинов оценивается как максимальное используемое количество среди трёх основных типов. Получено 6 180 магазинов и 10 929 используемых лицензий типов, то есть в среднем 1,768 типа лицензии на магазин.

Специализированные лицензии для других стран, интеграционный модуль Честного Знака и Set Mark Centrum Enterprise в эту оценку не включаются.

## REQ-MKT-005. Оценка нового годового дохода

**Область:** salesObjects
**Статус:** Подтверждено Product Manager
**Основание:** PM-DEC-095, PM-DEC-096
**Применимость:** Product discovery

При принятии решения 80% новых сетей ожидаемо охватываются около 338 клиентов и 4 914 магазинов.

| Тип лицензии | Доля в используемых лицензиях трёх типов | Ожидаемое количество лицензий | Новый валовый доход в год, с НДС |
|---|---:|---:|---:|
| Продовольственные товары | 33,2% | ≈ 2 883 | ≈ 11,53 млн ₽ |
| Непродовольственные товары | 29,3% | ≈ 2 549 | ≈ 10,20 млн ₽ |
| Alco | 37,5% | ≈ 3 259 | ≈ 13,04 млн ₽ |
| **Итого** | **100%** | **≈ 8 691 лицензия типов** | **≈ 34,76 млн ₽ в год** |

Расчёт каждого типа: `6 143 магазина × 80% вероятности покупки × (используемые лицензии типа / 6 180 текущих магазинов) × 4 000 ₽`. Количество лицензий типов больше количества магазинов, поскольку фактическая структура содержит в среднем 1,768 типа на магазин.

Дополнительные ориентиры:

- минимальная оценка при продаже ровно одного типа каждому купившему клиенту — около 19,66 млн ₽ в год;
- теоретический потенциал при 100% принятии и текущем количественном соотношении типов — около 43,45 млн ₽ в год.

## REQ-MKT-006. Ограничения оценки

**Область:** salesObjects
**Статус:** Подтверждено Product Manager
**Основание:** PM-DEC-095
**Применимость:** Product discovery

Оценка является экспресс-моделью. Основные источники неопределённости: отсутствие прямого количества магазинов у потенциальных клиентов, сопоставление страны по названию, неполная активация купленных лицензий и применение структуры текущих клиентов для прогноза спроса по типам. Результат следует использовать как ориентир порядка величины и обновить после получения прямого реестра магазинов и товарных профилей сетей.
