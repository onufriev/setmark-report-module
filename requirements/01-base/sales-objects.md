# Объект продажи модуля

## REQ-DEC-005. Объект продажи модуля

**Область:** salesObjects
**Статус:** Подтверждено Product Manager
**Основание:** PM-DEC-005; уточнение Product Manager от 2026-08-11
**Применимость:** MVP1

Объектом продажи является отдельная периодическая лицензия на модуль «Set Mark — мониторинг и анализ нарушений».

- Действующим клиентам Set Mark модуль продаётся как дополнительная лицензия.
- Новым клиентам модуль продаётся совместно с Set Mark.
- Единица тарификации и правила расчёта стоимости пока не определены.

Торговая сеть, магазин/торговая точка, касса, инцидент, кассовая операция и код маркировки являются объектами эксплуатации и анализа. Они не являются объектами продажи и не образуют коммерческую иерархию в рамках этого требования.

### Проверка

Коммерческое описание продукта выделяет отдельную периодическую лицензию на модуль как объект продажи, не подменяет её иерархией объектов эксплуатации и не фиксирует неподтверждённую единицу тарификации.
