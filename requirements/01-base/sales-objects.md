# Объекты продаж и коммерческая модель

## REQ-DEC-052. Функциональность входит в коробочное решение Set Mark

**Область:** salesObjects  
**Статус:** Подтверждено Product Manager  
**Основание:** PM-DEC-005  
**Применимость:** MVP1

Объектом продажи является коробочное решение Set Mark.

Функциональность «Мониторинг и анализ нарушений» входит в коробочное решение Set Mark и отдельно не лицензируется.

- Для действующих клиентов Set Mark функциональность предоставляется в составе используемого коробочного решения.
- Для новых клиентов функциональность предоставляется в составе приобретаемого коробочного решения.
- Отдельная единица лицензирования, отдельный тариф и отдельная стоимость для функциональности не устанавливаются.
- Настоящее требование не определяет стоимость коробочного решения Set Mark в целом.

Торговая сеть, магазин/торговая точка, касса, инцидент, кассовая операция и код маркировки являются объектами предметной области, эксплуатации и анализа. Они не являются автоматически объектами продажи и не образуют коммерческую иерархию в рамках текущего MVP.

### Проверка

Коммерческое описание продукта и пользовательские материалы представляют функциональность «Мониторинг и анализ нарушений» как часть коробочного решения Set Mark, не выделяют её в отдельную лицензию и не указывают отдельную стоимость.
