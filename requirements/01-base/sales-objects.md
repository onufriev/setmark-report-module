# Объект продажи решения

## REQ-DEC-005. Объект продажи решения

**Область:** salesObjects  
**Статус:** Подтверждено Product Manager  
**Основание:** PM-DEC-005; уточнения Product Manager от 2026-08-11 и 2026-08-26  
**Применимость:** MVP1

Объектом продажи является коробочное решение Set Mark.

Функциональность «Мониторинг и анализ нарушений» входит в состав коробочного решения Set Mark и отдельно не лицензируется.

- Для действующих клиентов функциональность предоставляется в составе решения Set Mark без отдельной лицензии на модуль.
- Для новых клиентов функциональность входит в приобретаемое коробочное решение Set Mark.
- Отдельные единица тарификации, стоимость и правила лицензирования для этой функциональности не устанавливаются.
- Настоящее требование не определяет стоимость и правила лицензирования коробочного решения Set Mark в целом.

Торговая сеть, магазин/торговая точка, касса, инцидент, кассовая операция и код маркировки являются объектами эксплуатации и анализа. Они не являются объектами продажи и не образуют коммерческую иерархию в рамках этого требования.

### Проверка

Коммерческое описание продукта представляет функциональность «Мониторинг и анализ нарушений» как часть коробочного решения Set Mark, не выделяет её в отдельную лицензию и не указывает отдельную стоимость.
