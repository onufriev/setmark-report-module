# Продуктовый контекст

## REQ-DEC-004. Продуктовый контекст

**Область:** productContext
**Статус:** Подтверждено Product Manager
**Основание:** PM-DEC-004, PM-DEC-019
**Применимость:** MVP1

Утверждён продуктовый контекст. Бизнес-цель уточнена Product Manager 27.08.2026:

- Проблема: ответственные сотрудники торговой сети слишком поздно обнаруживают отклонения при продаже маркированных товаров; нарушения накапливаются, а их причины и место устранения трудно определить по разрозненным данным.
- Продуктовая граница: новая функция внутри существующего продукта Set Mark, использующая данные и механизмы Set Mark; это не самостоятельный продукт и не автономный программный модуль.
- Пользователи: ответственные сотрудники торговой сети; конкретные роли и права определяются отдельно в Q-007.
- Результат: пользователь видит нарушение, понимает, где и почему оно возникло, оценивает регуляторный риск и получает рекомендацию по устранению.
- Бизнес-цель: главная бизнес-цель функции — снизить риск получения торговой сетью штрафов за нарушения при работе с маркированными товарами. Для достижения этой цели функция должна сокращать время обнаружения нарушений, помогать предотвращать их повторение и снижать накопление нарушений и совокупный регуляторный риск.
- Границы: применяются утверждённые границы MVP из Q-002.
- Коммерческая модель: пока не определена и этим решением не фиксируется.

### Проверка

Реализация соответствует решению PM-DEC-004 и явно связывает ценность функции со снижением риска получения штрафов за нарушения маркировки.

## Что необходимо зафиксировать при закрытии вопроса

- проблему и цель продукта;
- целевую аудиторию и контекст использования;
- границы продукта и то, что не входит в первую версию;
- ключевые бизнес-цели и критерии успеха;
- известные ограничения;
- планируемые объекты продаж: лицензия, оборудование или услуга, если применимо;
- периодичность оплаты и принцип формирования цены, если они уже определены.

Неизвестные решения остаются отдельными `NEEDS_INPUT` и не заменяются предположениями.

## REQ-PC-001. Назначение продукта

**Область:** productContext
**Статус:** Подтверждено источником
**Основание:** SRC-EV-001, SRC-EV-002
**Применимость:** MVP1

Новая функция Set Mark должна предоставить ритейлеру централизованный инструмент мониторинга нарушений маркировки, оперативных уведомлений и рекомендаций по исправлению, чтобы снижать риск позднего обнаружения и значительного накопления нарушений.

### Проверка

Назначение продукта в требованиях и пользовательских сценариях включает мониторинг, уведомления и рекомендации и не сводится только к просмотру исходного отчёта.

## REQ-PC-002. Контекст Set Mark

**Область:** productContext
**Статус:** Подтверждено источником
**Основание:** SRC-EV-011
**Применимость:** MVP1

Функция создаётся внутри Set Mark — продукта экосистемы Set Retail 10 для контроля розничной продажи маркированного товара.

### Проверка

Описание функции и границы интеграций явно фиксируют её как часть Set Mark и связывают с Set Retail 10.
