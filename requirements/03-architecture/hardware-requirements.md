# Оборудование

## REQ-DEC-012. Решение Product Manager

**Область:** hardware
**Статус:** Подтверждено Product Manager
**Основание:** PM-DEC-012
**Применимость:** MVP1

Для MVP специальное пользовательское оборудование модулю не требуется. Кассы, SCO, сканеры и другое торговое оборудование не управляются модулем напрямую: модуль анализирует данные, поступившие через Set Mark, Set Retail и Set Centrum. Модели оборудования, подключение периферии, замена и ремонт не входят в границы модуля. Недоступность оборудования отражается только через отсутствие, задержку или неполноту данных. Отдельное оборудование в составе поставки модуля не продаётся. Действуют существующие требования платформ Set Mark и Set Retail 10.

### Проверка
Реализация соответствует решению PM-DEC-012.
## Что необходимо зафиксировать при закрытии вопроса

- типы устройств и их назначение;
- обязательное оборудование на стороне пользователя, торговой точки или заказчика;
- поддерживаемые модели, классы или минимальные характеристики;
- периферийные устройства и способы подключения;
- ограничения операционной системы, сети и интерфейсов;
- оборудование, входящее в поставку или продаваемое отдельно;
- сценарии замены, ремонта и повторного подключения;
- важные состояния оборудования и реакции продукта;
- либо явное подтверждение, что специальное оборудование не требуется.

Оборудование является продуктовым входом, если влияет на границы продукта, сценарии, поставку, интеграции или объекты продаж. Инфраструктурный сайзинг серверов сюда не относится.
