# Источник интерфейса и компонентов

## REQ-DEC-011. Источник интерфейса и компонентов

**Область:** uiSource
**Статус:** Подтверждено Product Manager
**Основание:** PM-DEC-011, PM-DEC-019
**Применимость:** MVP1

Основным источником компонентов для новой функции Set Mark является корпоративная библиотека `@crystalservice/csi_ui` версии `1.30.3`. Актуальный frontend Set Mark в `application/ui/modules/frontend` используется как источник визуального языка и референс применения компонентов библиотеки. Устаревший frontend в `application/setmark/modules/web-frontend` может использоваться только как дополнительный источник реализованных сценариев, но не как дизайн-основа.

Для создаваемого визуального прототипа разрешено переиспользовать подтверждённые компоненты библиотеки и паттерны актуального frontend Set Mark, включая каркас приложения, навигацию, верхнюю панель, breadcrumbs, таблицы, фильтры, пагинацию, диалоги, статусные метки, индикаторы загрузки и пустые состояния.

Исходники `@crystalservice/csi_ui` в переданном снимке приложения отсутствуют. Для визуального прототипа допустимо воспроизвести наблюдаемые правила использования компонентов. Для сборки рабочего интерфейса необходим доступ к корпоративному npm-реестру.

Изменение библиотечных компонентов и создание отсутствующих компонентов этим решением не разрешены и требуют отдельного решения Product Manager. Отсутствующие компоненты должны быть зафиксированы как ограничение и влияние на прототип.

### Проверка

Визуальный прототип использует зарегистрированный источник `COMPONENT_LIBRARY`, продолжает визуальный язык актуального frontend Set Mark и не выдаёт существующее приложение или библиотеку компонентов за готовый прототип.
