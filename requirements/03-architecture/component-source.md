# Источник интерфейса и компонентов

## REQ-DEC-066. Решение Product Manager

**Область:** uiSource
**Статус:** Подтверждено Product Manager
**Основание:** PM-DEC-067
**Применимость:** MVP1

В интерфейсе Set Mark применяются раздельные визуальные эталоны. Оболочка, боковое меню и продуктовая навигация воспроизводят действующий SetCentrum; Set Mark размещается рядом с Set Loyalty как отдельный продукт, а оригинальные логотипы SetRetail10, Set Loyalty и SetMark используются с сохранением пропорций. Журнал нарушений, его таблицы и фильтры продолжают действующую визуализацию Журнала; новые экраны Мониторинга маркировки используют компоненты и визуальный язык `@crystalservice/csi_ui`. В автономном прототипе пункты вне Set Mark могут быть безопасными заглушками, сохраняющими визуальный контекст меню. Актуальный frontend Set Mark может использоваться как референс существующих сценариев, но больше не является основой всей оболочки. Это требование заменяет соответствующую часть REQ-DEC-011.

### Проверка
Реализация соответствует решению PM-DEC-067.
## REQ-DEC-011. Источник интерфейса и компонентов

**Область:** uiSource
**Статус:** Подтверждено Product Manager
**Основание:** PM-DEC-011, PM-DEC-019, PM-DEC-067
**Применимость:** MVP1

Основным источником компонентов для новых экранов Мониторинга маркировки является корпоративная библиотека `@crystalservice/csi_ui` версии `1.30.3`. Актуальный frontend Set Mark в `application/ui/modules/frontend` используется как источник действующей визуализации Журнала нарушений и референс существующих сценариев. Устаревший frontend в `application/setmark/modules/web-frontend` может использоваться только как дополнительный источник реализованных сценариев, но не как дизайн-основа.

Для создаваемого визуального прототипа разрешено переиспользовать подтверждённые компоненты библиотеки и паттерны соответствующего визуального эталона, включая верхнюю панель, breadcrumbs, таблицы, фильтры, пагинацию, диалоги, статусные метки, индикаторы загрузки и пустые состояния. Каркас приложения и продуктовая навигация воспроизводят SetCentrum согласно REQ-DEC-066.

Исходники `@crystalservice/csi_ui` в переданном снимке приложения отсутствуют. Для визуального прототипа допустимо воспроизвести наблюдаемые правила использования компонентов. Для сборки рабочего интерфейса необходим доступ к корпоративному npm-реестру.

Изменение библиотечных компонентов и создание отсутствующих компонентов этим решением не разрешены и требуют отдельного решения Product Manager. Отсутствующие компоненты должны быть зафиксированы как ограничение и влияние на прототип.

### Проверка

Визуальный прототип использует зарегистрированные источники в установленных границах и не выдаёт существующее приложение или библиотеку компонентов за готовый прототип.
