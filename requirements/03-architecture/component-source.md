# Источник интерфейса и компонентов

## NEEDS_INPUT: Источник интерфейса и компонентов

**ID вопроса:** Q-009
**Область:** uiSource
**Статус:** Требуется решение

**Вопрос:** Откуда брать реальные компоненты и визуальные правила: продукт, Figma, Storybook, библиотека или нейтральный UI?
**Что известно:** Пока не установлено из подтверждённых источников.
**Почему важно:** Без подтверждённого источника UI нельзя достоверно строить визуальный прототип.
**Рекомендация Product Compiler:** Сформировать предложение только после анализа источников; не применять без подтверждения Product Manager.

## Что необходимо зафиксировать при закрытии вопроса

Допустимые варианты источника UI:

- Figma-файл, библиотека или проект с компонентами;
- Storybook или иная опубликованная компонентная библиотека;
- существующий репозиторий/код продукта, из которого берутся компоненты и визуальные правила;
- явное решение создать новую компонентную базу;
- нейтральный UI — только как отдельное подтверждённое решение Product Manager.

Нужно отдельно указать, что разрешено переиспользовать, изменять и создавать. Если выбран существующий источник, новые компоненты нельзя создавать без явного разрешения Product Manager. Отсутствующие компоненты фиксируются как ограничение и влияние на прототип.

Подтверждённый источник UI обязателен до этапа `VISUAL_PROTOTYPE`; он не должен блокировать сбор продуктовых требований.
