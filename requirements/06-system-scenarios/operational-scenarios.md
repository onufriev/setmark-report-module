# Эксплуатационные сценарии жизненного цикла

## REQ-DEC-022. Решение Product Manager

**Область:** operationalScenarios
**Статус:** Подтверждено Product Manager
**Основание:** PM-DEC-022
**Применимость:** MVP1

Для функции внутри Set Mark применяются следующие эксплуатационные сценарии жизненного цикла: у функции нет отдельной установки, первоначальной настройки и развёртывания — она поставляется как часть Set Mark; обновление и откат выполняются штатными средствами Set Mark; резервное копирование, восстановление, миграция и вывод из эксплуатации выполняются на уровне Set Mark и его данных; после перезапуска функция автоматически продолжает обработку сохранённых событий; при недоступности сети или источника отображаются свежесть и полнота данных, а накопленные события обрабатываются после восстановления; частичная недоступность не скрывается — пользователю показываются доступные данные и влияние сбоя; замену интеграции или зависимого компонента выполняет Set Mark, функция продолжает работать при сохранении установленного контракта данных; отдельные эксплуатационные инструкции, администратор и процедуры обслуживания для функции не требуются; эксплуатационные сбои функции не влияют на продажи и проверку кодов.

### Проверка
Реализация соответствует решению PM-DEC-022.
## Сценарии, которые нельзя игнорировать

Для каждого пункта необходимо подтвердить применимость или явно зафиксировать «не применимо»:

1. Первая установка.
2. Первичная настройка.
3. Развёртывание в новом окружении или подразделении.
4. Обновление приложения или компонентов.
5. Неуспешное обновление и откат.
6. Резервное копирование.
7. Восстановление данных и конфигурации.
8. Перезапуск после аварийного завершения.
9. Недоступность сети.
10. Недоступность внешнего сервиса.
11. Частичная недоступность системы.
12. Перенос или миграция данных.
13. Замена зависимого компонента или интеграции.
14. Вывод из эксплуатации.
