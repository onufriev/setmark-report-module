# Исключительные сценарии

## REQ-DEC-020. Решение Product Manager

**Область:** exceptionScenarios
**Статус:** Подтверждено Product Manager
**Основание:** PM-DEC-020
**Применимость:** MVP1

Для MVP функция должна обрабатывать исключительные сценарии следующим образом: если данные не обновлялись более 24 часов, показывать предупреждение и время последнего обновления; при доступности только части данных показывать доступную часть и присваивать инциденту результат анализа RA-04 с перечнем недостающих данных; неизвестному типу отклонения присваивать RA-05 без формирования выдуманного результата анализа; при ошибке обработки сохранять исходное событие и автоматически повторять обработку; повторная доставка одного события не должна создавать дубликат инцидента; после восстановления источника отложенные данные должны обрабатываться автоматически; отсутствие прав не должно раскрывать данные недоступного объекта; сбои существующих интеграций обрабатывает Set Mark, а функция отображает их состояние и влияние на данные; ни один сбой функции не должен влиять на продажи и проверку кодов.

### Проверка
Реализация соответствует решению PM-DEC-020.
