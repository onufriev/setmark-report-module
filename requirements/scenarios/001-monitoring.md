# Сценарий 1. Мониторинг нарушений

## Цель

Понять, где есть проблемы с маркированными продажами.

## Пользователь

Аналитик по работе с маркировкой или другой сотрудник с доступом к организации.

## Основной ход

1. Пользователь открывает мониторинг Set Mark.
2. Продукт показывает магазины, продажи и отклонения с состояниями и временем обновления.
3. Пользователь фильтрует список по магазину, периоду или состоянию.
4. Пользователь открывает нужное отклонение и видит его детали.

## Результат

Пользователь находит проблемный объект и понимает, что требует внимания.

## Другие варианты

- При отсутствии отклонений показывается понятное пустое состояние.
- При неполных данных доступная часть сохраняется, а ограничение заметно пользователю.

## Условия готовности

- Проблемный магазин или отклонение можно найти без просмотра всех карточек.
- Детали содержат причину, статус и время проверки.
- Фильтры не скрывают состояние доступности данных.
