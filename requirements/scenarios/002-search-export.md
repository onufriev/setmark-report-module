# Сценарий 2. Поиск и выгрузка

## Цель

Найти продажи и товары по известным признакам и передать результат для дальнейшей работы.

## Пользователь

Аналитик по работе с маркировкой.

## Основной ход

1. Пользователь задаёт штрихкод, артикул, код маркировки, магазин или период.
2. Продукт показывает подходящие продажи и связанные отклонения.
3. Пользователь выбирает нужный набор и запускает выгрузку.
4. Продукт формирует файл с выбранными сведениями.

## Результат

Пользователь получает проверяемый набор данных для анализа или передачи коллегам.

## Другие варианты

- При отсутствии совпадений продукт показывает пустой результат.
- Если выгрузка неполна, продукт сообщает об этом до использования файла.

## Условия готовности

- Поддерживаются согласованные признаки поиска и несколько магазинов.
- Выгрузка отражает применённые фильтры и период.
