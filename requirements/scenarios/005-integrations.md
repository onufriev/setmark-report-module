# Сценарий 5. Получение данных проверок

## Цель

Использовать результаты подключённых проверок в едином мониторинге.

## Пользователь

Пользователь мониторинга Set Mark.

## Основной ход

1. Продукт получает доступные результаты проверки.
2. Продукт связывает результат с магазином, продажей и товаром.
3. Пользователь видит результат в мониторинге и может открыть детали.

## Результат

Результаты внешних проверок доступны в понятном продуктовом контексте.

## Другие варианты

- При разрыве связи продукт показывает последнее доступное состояние и ограничение.

## Условия готовности

- Пользователь отличает свежие данные от устаревших.
- Связь результата с объектом продажи не теряется.
