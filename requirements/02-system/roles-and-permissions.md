# Роли и права доступа

## REQ-DEC-008. Решение Product Manager

**Область:** rolesPermissions
**Статус:** Подтверждено Product Manager
**Основание:** PM-DEC-008, PM-DEC-010
**Применимость:** MVP1

В продукте первичны отдельные привилегии, а не строго зафиксированные роли. Роль представляет собой изменяемый набор привилегий. Управление ролями, назначение и исключение привилегий выполняются существующими средствами Set Centrum; отдельный инструмент управления ролями и привилегиями в модуле не создаётся.

Для MVP зафиксирован следующий каталог привилегий:

- просмотр общего обзора и аналитики по нарушениям;
- просмотр списка и карточки инцидентов, включая исходные данные, объяснение результата анализа, риски и рекомендации;
- фильтрация и поиск инцидентов;
- выгрузка доступных данных в CSV;
- получение настроенных уведомлений о критичных нарушениях;
- настройка подключения к True API;
- настройка получателей уведомлений;
- настройка срока хранения данных.

Роли по умолчанию:

- «Аналитик по работе с маркировкой» получает первые пять рабочих привилегий, связанных с просмотром, анализом, выгрузкой и получением уведомлений;
- «Администратор системы» получает весь каталог привилегий, включая три административные настройки.

Состав обеих ролей по умолчанию может быть изменён в Set Centrum. Все привилегии на просмотр, анализ и выгрузку действуют только в пределах сетей и торговых точек, доступных пользователю согласно настройкам Set Centrum. Получатель уведомлений не является отдельной ролью. Назначение ответственных, управление задачами и контроль исправления в MVP не вводятся. Способ аутентификации и техническая интеграция с существующей моделью доступа определяются отдельно.

### Проверка
Реализация соответствует решениям PM-DEC-008 и PM-DEC-010.
