# Ошибки, пустые и недоступные состояния

## REQ-DEC-071. Решение Product Manager

**Область:** statesErrors
**Статус:** Подтверждено Product Manager
**Основание:** PM-DEC-072
**Применимость:** MVP1

Для клиента RU после проверки прав применяются следующие состояния. При действующей лицензии доступ полный. При лицензионном несоответствии доступ полный с неблокирующим предупреждением. В течение 10-дневного льготного периода доступ полный с предупреждением и остатком срока. В состояниях «лицензии никогда не было» и «льготный период закончился» доступен усечённый Обзор, Журнал недоступен, разделы Мониторинга открывают заглушки, экспорт, массовый поиск и уведомления запрещены, а в Настройках разрешён только запуск подключения ЭЦП. При неизвестном статусе без достоверной истории применяется такое же ограничение с отдельным предупреждением. При недоступности Set Agent и наличии достоверной даты окончания состояние пересчитывается по этой дате, включая льготный период, с предупреждением о невозможности актуализации. «Лицензии никогда не было» назначается только при явном подтверждении полной истории Set Agent. Предупреждения должны отличаться от ошибок доступа, объяснять конкретное состояние и не блокировать функции при полном доступе.

### Проверка
Реализация соответствует решению PM-DEC-072.
## REQ-DEC-038. Решение Product Manager

**Область:** statesErrors
**Статус:** Подтверждено Product Manager
**Основание:** PM-DEC-039
**Применимость:** MVP1

В блоке «Состояние данных» показываются только два сигнала:

1. Результат последнего обращения в «Честный знак» за отчётом — успешно или с ошибкой — с датой и временем обращения.
2. Наличие или отсутствие связи с Set Centrum.

Без связи с Set Centrum анализ инцидентов невозможен. Проценты полноты, количество пропущенных записей и оценка качества данных в этом блоке не показываются.

### Проверка
Реализация соответствует решению PM-DEC-039.
## REQ-DEC-009. Решение Product Manager

**Область:** statesErrors
**Статус:** Подтверждено Product Manager
**Основание:** PM-DEC-009
**Применимость:** MVP1

Для MVP утверждены следующие ошибки, пустые и недоступные состояния:

- Если нарушений за выбранный период нет, система показывает сообщение «Нарушения не обнаружены».
- Если данным не соответствует текущий набор фильтров, система сообщает об отсутствии результатов и предлагает действие «Сбросить фильтры».
- Во время загрузки система показывает индикатор загрузки и не выдаёт устаревший результат за актуальный.
- При задержке обновления данных система показывает предупреждение и время последнего успешного обновления.
- Если часть источников недоступна, система показывает доступные данные и явно отмечает недоступные.
- Если данных недостаточно для анализа, инцидент получает результат RA-04 — Недостаточно данных с перечнем отсутствующих данных.
- Если тип отклонения неизвестен, инцидент получает результат RA-05 — Требуется обновление правил анализа.
- Пока инцидент анализируется, система показывает статус «Анализируется», а итог и рекомендации ещё не показывает.
- При ошибке обработки система показывает статус «Ошибка обработки», понятное описание и идентификатор инцидента.
- Если у пользователя нет прав на объект, система сообщает об отсутствии доступа и не раскрывает данные объекта.
- При ошибке настройки интеграции Администратор системы видит проблемное подключение и причину ошибки.

### Проверка
Реализация соответствует решению PM-DEC-009.
