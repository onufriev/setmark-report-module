# Пользовательские пути

## REQ-DEC-042. Решение Product Manager

**Область:** mainJourney
**Статус:** Подтверждено Product Manager
**Основание:** PM-DEC-043
**Применимость:** MVP1

Пользователь выбирает готовый или произвольный период, оценивает показатели Дашборда, критические объекты, типы нарушений и необходимые действия; по кликабельным агрегатам переходит к точно соответствующей выборке инцидентов; уточняет её поиском и множественными фильтрами; открывает карточку, видит полный код маркировки, объяснение и потенциальный штраф; при необходимости выгружает PDF.

На вкладке «Аналитика» пользователь включает фильтры критичности и подтверждённых нарушений, получает пересчитанные показатели и график и переходит из выбранной колонки к составившим её инцидентам.

### Проверка
Реализация соответствует решению PM-DEC-043.
## REQ-DEC-024. Решение Product Manager

**Область:** mainJourney
**Статус:** Подтверждено Product Manager
**Основание:** PM-DEC-024
**Применимость:** MVP1

Для MVP основной пользовательский путь аналитика внутри Set Mark должен выполняться следующим образом: пользователь входит в Set Mark через существующий механизм аутентификации; открывает раздел мониторинга нарушений маркировки; на обзоре сети видит период, согласованные сигналы состояния данных, общие показатели и объекты с наибольшим риском; выбирает магазин, кассу, товарную группу либо вид нарушения и переходит к отфильтрованному списку инцидентов; при необходимости уточняет фильтры и сортировку; открывает карточку инцидента; изучает исходные данные, понятный результат проверки без технического кода `RA-*`, объяснение, критичность, потенциальный штраф, Контур устранения и рекомендацию; возвращается к списку или аналитике с сохранением выбранного контекста; при необходимости выгружает текущую выборку в CSV. Дополнительные точки входа: из ежедневного уведомления пользователь переходит в Set Mark к соответствующему инциденту или отфильтрованной выборке; администратор открывает настройки функции для управления подключением, получателями уведомлений и сроком хранения данных; при недостаточных правах, неполных или устаревших данных интерфейс показывает доступный результат и понятное ограничение.

### Проверка
Реализация соответствует решению PM-DEC-024.
