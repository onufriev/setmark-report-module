# Рабочий прототип

Экспериментальная реализация для клиентской проверки, не production-ready.

До создания кода должны быть подтверждены:

- технологический стек;
- источник данных в `product/prototype-data-source.json`.

Обязательны `prototype-manifest.json`, полностью заполненный `PROTOTYPE-RUNBOOK.md`, точка входа, команды запуска/остановки, настройка окружения, подготовка и сброс данных, health-check и проверяемый основной сценарий.
