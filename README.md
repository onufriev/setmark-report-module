# Product Compiler

Product Compiler переводит материалы и ответы Product Manager в понятное
продуктовое видение, сценарии, необязательные прототипы и комплект передачи в
системную аналитику.

## Основные гарантии

- требования организованы по законченным действиям пользователя;
- решение Product Manager уточняет сценарий или правило, а не создаёт безымянное требование;
- служебные ссылки на источники скрыты из основного текста, но проверяются инструментами;
- подробно описывается текущая версия, а будущее развитие остаётся компактным;
- Product Compiler не проектирует production-архитектуру и не отвечает за техническое развитие;
- неблокирующие вопросы можно оставить следующему этапу;
- визуальный и рабочий прототипы необязательны;
- стек и источник данных рабочего прототипа обязательны только при выборе этой ветки;
- handoff содержит продуктовые требования и открытые пункты без придуманной архитектуры;
- `project-state.json` пересчитывается автоматически.

## Быстрый старт

Один раз установите зависимости:

```text
python -m pip install -r requirements-tooling.txt
```

Затем напишите агенту: `Начни работу над продуктом`.

Product Manager указывает источники или описывает идею, определяет текущую
версию и отвечает только на действительно блокирующие продуктовые вопросы.
Подробный порядок — в `START-HERE.md` и `PRODUCT-COMPILER.md`.

## Завершение

После `HANDOFF_READY` системный аналитик или PO продолжает работу над CR через
change compiler и формирует системные требования в
[set-requirements](https://github.com/crystalservice/set-requirements).
