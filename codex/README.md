# Codex: локальный плагин критиков

Папка содержит готовый **Local Developer Plugin** для Codex:

`codex/csi-critic-agents`

Внутри находятся все critic skills. Это отдельная копия инструкций, адаптированная к формату skills Codex. Исходные читаемые версии лежат в `critics/agents/`.

## Подключение без терминала

1. Откройте Product Compiler в Codex.
2. Перейдите в **Settings → Plugins**.
3. Добавьте локальный developer plugin и выберите папку:
   `codex/csi-critic-agents`.
4. Убедитесь, что **CSI Critic Agents** включён.
5. Откройте новый диалог после подключения или обновления skills.

Название пункта интерфейса может отличаться между версиями Codex. Ориентир — локальный плагин разработчика и выбор папки, содержащей `.codex-plugin/plugin.json`.

## Использование

Codex может выбрать skill по смыслу запроса. Для обязательной проверки называйте его явно:

- `Используй vera-critic-pm и проверь требования.`
- `Используй uiux-critic и проверь visual-prototype.`
- `Используй architect-critic и проверь рабочий прототип.`

Можно использовать команды, описанные внутри конкретного skill, например `*analyze` или `*quick`. Это инструкции skill, а не отдельные команды CLI.

## Добавление нового skill

Создайте папку:

`codex/csi-critic-agents/skills/<skill-name>/skill.md`

Файл должен начинаться с YAML-блока `name` и `description`. После изменения откройте новый диалог Codex; при необходимости перезагрузите окно приложения.
