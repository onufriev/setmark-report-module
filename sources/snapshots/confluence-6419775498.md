## Проверенные выдержки

### Проблематика

Ключевой риск: с запуском автоматического назначения штрафов за нарушения в сфере маркировки ритейлер может узнавать о проблемах слишком поздно — уже после возникновения серьезных финансовых последствий.

Нет предупреждений от «Честного знака». Система не информирует участника оборота заранее о допущенных нарушениях. Ритейлер узнаёт о проблеме уже по факту самостоятельно через ЛК ЧЗ.

Нет единого мониторинга по сети. На стороне SetRetail10 фиксируются события и ошибки проверки кодов маркировки, но отсутствует централизованный инструмент, который агрегирует нарушения по магазинам, кассам и товарным категориям.

Нет понимания как исправить ситуацию. Компания зачастую не в состоянии самостоятельно разобраться в причинах и принять адекватные меры для устранения проблемы.

### Предлагаемое решение

Идея решения: предоставить ритейлеру централизованный инструмент мониторинга нарушений маркировки, оперативных уведомлений и рекомендаций по исправлению, чтобы предотвращать автоштрафы до их значительного накопления.

Сбор событий SetMark/SetRetail10 — фиксация ошибок проверки кодов маркировки, отклонённых марок, нарушений разрешительного режима и других событий с касс.

Централизованный мониторинг — агрегированное отображение нарушений по сети магазинов, торговым точкам, кассам, товарным категориям и типам ошибок.

Оперативные уведомления — информирование ответственных сотрудников о критичных нарушениях в ежедневном режиме.

Аналитика причин и рекомендации — выявление системных проблем: некорректных настроек касс, отключённого разрешительного режима, ошибок валидации или проблем с отдельными категориями товаров.

### Интеграция с API «Честный знак»

Цель: дополнить внутренние данные Set Mark информацией об отклонениях, зафиксированных на стороне ГИС МТ («Честный знак»), чтобы обнаруживать нарушения, которые не были перехвачены кассовым ПО.

Реализовать периодический опрос API ЧЗ по методу 8.3.15.1 «Выгрузка сведений об отклонениях» для получения списка нарушений, зарегистрированных регулятором для ИНН клиента.

Сопоставлять отклонения из ЧЗ с записями журнала нарушений SetMark по коду маркировки (КМ) и временно́й метке: если отклонение имеет соответствие в журнале SetMark — связать записи; если отклонение не имеет соответствия — получить последний успешный результат проверки в ЧЗ (онлайн или офлайн)

### Мониторинг и детализация

Цель: предоставить ответственным сотрудникам единый интерфейс для обзора, фильтрации и анализа нарушений по всей розничной сети.

Возможность выгрузить любые сведения в CSV.

### Уведомления

Цель: обеспечить информирование ответственных лиц о критичных нарушениях в ежедневном режиме

Каналы доставки уведомлений: электронная почта;

### Нефункциональные требования

Производительность: обработка событий от касс без заметного влияния на работу продажи.

Масштабируемость: поддержка сетей с большим количеством магазинов и кассовых узлов.

Надёжность: сохранение событий при временных сбоях связи и последующая доставка данных в центральный контур.
