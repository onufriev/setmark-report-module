# Пример диалога

**Product Compiler:** Чтобы описать основный сценарий, нужно понять одно: какое
законченное действие должен выполнить пользователь и что он должен получить в
результате? Без этого нельзя определить текущую версию продукта.

Остальные вопросы — состав полей, способ загрузки большого списка и технический
обмен между системами — сейчас не блокируют работу. Я сохраню их для следующих
этапов.

**Product Manager:** Пользователь должен увидеть проблемные магазины, найти
нужную камеру и открыть её карточку.

**Product Compiler:** Ответ зарегистрирован и встроен в сценарий «Просмотр камер
по магазинам». В сценарии описаны действия, результат и видимые исключения.
Технический способ получения состояния камер оставлен системному аналитику.
