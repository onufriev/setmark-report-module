# Передача продуктовых требований

`handoff/` содержит зафиксированное продуктовое видение для системного аналитика,
архитектора и команды разработки.

В комплект входят:

- видение и границы продукта;
- утверждённые пользовательские сценарии;
- общие продуктовые правила;
- наблюдаемые требования к качеству;
- открытые вопросы с будущими владельцами;
- ссылки на результаты проверки прототипа, если он создавался;
- служебная трассировка отдельным приложением.

Handoff не содержит архитектуру, технический план, придуманные API, структуры БД
или внутренние алгоритмы. Он не пересказывает каждый сценарий другими словами:
основные тексты переносятся без смыслового изменения, а `README.md` даёт порядок
чтения и краткую карту.

После передачи системный аналитик или PO формирует системные требования через
change compiler и `set-requirements`.
