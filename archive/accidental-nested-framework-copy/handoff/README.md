# Передача продуктовых требований

Каталог заполняется на этапе `HANDOFF_READY` после фиксации требований.

Комплект для передачи содержит:

- краткий порядок чтения и границы текущей версии;
- точный снимок читаемых продуктовых требований из `requirements/`;
- открытые пункты с будущими владельцами;
- ссылку на результат проверки прототипа, если прототип был выбран;
- необязательное приложение со служебной трассировкой.

Комплект не создаёт архитектуру, API, структуру данных или технический план и не
пересказывает каждый сценарий другими словами. Если исходные требования
нечитаемы, сначала исправляются они, а не их производная копия.

После завершения системный аналитик или PO продолжает работу над CR через change
compiler и [set-requirements](https://github.com/crystalservice/set-requirements).
