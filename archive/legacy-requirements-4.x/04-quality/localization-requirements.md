# Локализация и форматы

## REQ-DEC-172. Решение Product Manager

**Область:** localization
**Статус:** Подтверждено Product Manager
**Основание:** PM-DEC-187
**Применимость:** Следующий этап

Ежедневный email-дайджест, его тема, показатели, подписи и сообщения об ошибках формируются на русском языке. Расчёт предыдущего календарного дня и запуск отправки в 09:00 выполняются в часовом поясе SetCentrum; даты и время отображаются в российских форматах.

### Проверка
Реализация соответствует решению PM-DEC-187.

## REQ-DEC-072. Решение Product Manager

**Область:** localization
**Статус:** Подтверждено Product Manager
**Основание:** PM-DEC-075
**Применимость:** MVP1

При корректном нормализованном значении `setmark.country`, отличном от `RU`, Мониторинг маркировки полностью отсутствует: система не показывает его навигацию и подключение ЭЦП к «Честному знаку», не предоставляет страницы, прямые ссылки и API Мониторинга и не запускает сбор, обработку или хранение его данных. Журнал нарушений Set Mark продолжает работать по действующим правилам лицензирования и локализации. Ограничение страны имеет приоритет над лицензией и ролью пользователя.

### Проверка
Реализация соответствует решению PM-DEC-075.
## REQ-DEC-071. Решение Product Manager

**Область:** localization
**Статус:** Подтверждено Product Manager
**Основание:** PM-DEC-074
**Применимость:** MVP1

Единственным источником страны установки является нормализованное значение `setmark.country`. Значение приводится к верхнему регистру с удалением окружающих пробелов; пустое, отсутствующее или некорректное значение нормализуется в `RU`. Для результата `RU` применяется российская модель работы, включая Мониторинг маркировки, интеграцию с «Честным знаком» и подключение ЭЦП.

### Проверка
Реализация соответствует решению PM-DEC-074.
## REQ-DEC-016. Решение Product Manager

**Область:** localization
**Статус:** Подтверждено Product Manager
**Основание:** PM-DEC-016, PM-DEC-019, PM-DEC-075, PM-DEC-160
**Применимость:** MVP1

Для MVP Мониторинг маркировки должен работать на русском языке; другие локализации и переключение языка для Мониторинга не требуются, поскольку «Честный знак» действует только в России. Действующий Журнал нарушений в других странах сохраняет собственные правила локализации Set Mark. Обзор, список Инциденты, карточка, настройки и сообщения синхронизации отображаются на русском языке. Дата показывается в формате ДД.ММ.ГГГГ, время — в 24-часовом формате. В карточке инцидента показывается местное время магазина с указанием часового пояса; агрегаты рассчитываются в выбранном часовом поясе сети. Числа оформляются по российским правилам. Локализация уведомлений, отчётов, Аналитики, CSV и PDF относится к следующему этапу.

### Проверка
Реализация соответствует решению PM-DEC-016.
## Что необходимо зафиксировать при закрытии вопроса

- поддерживаемые языки и язык по умолчанию;
- необходимость и способ переключения языка;
- форматы дат, времени, чисел и валют;
- часовые пояса;
- локализацию сообщений, отчётов и экспортов;
- иные региональные особенности.

Если специальных требований нет, Product Manager должен явно подтвердить неприменимость. Пустой раздел или отсутствие ответа блокируют VISUAL_PROTOTYPE.
