# Версионирование Product Compiler

Версия продукта и версия формата данных независимы.

## Версия продукта

Единственный источник — корневой файл `VERSION`.

Инструменты читают его через `PRODUCT_VERSION` из `tools/common.py`. Номер релиза нельзя дублировать в Python-коде, JSON Schema, заголовках документов или тестах.

При выпуске новой версии Product Compiler изменяется только `VERSION`, если JSON-контракт не менялся.

## Версия JSON-контракта

Единственный источник — `schemas/schema-version.schema.json`:

- `x-currentVersion` — версия, которую записывают инструменты;
- `enum` — версии, которые могут быть прочитаны для обратной совместимости.

Все прикладные JSON Schema ссылаются на этот контракт через `$ref`. Они не содержат номер версии самостоятельно.

Версия JSON-контракта повышается только при изменении структуры или семантики сохраняемых JSON-документов. Она не повышается из-за нового релиза, новых инструкций, исправления алгоритма или изменения документации.

## Миграция

`common.load()` принимает поддерживаемые старые версии, а `common.save()` сохраняет документ в текущей версии контракта. Поэтому миграция выполняется штатной записью и не требует массовой ручной замены.
