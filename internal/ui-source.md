# Источник UI

Источник UI задаёт визуальные правила и доступные компоненты. Допустимы только три типа:

- `FIGMA` — ссылка на Figma-файл, страницу или библиотеку;
- `COMPONENT_LIBRARY` — ссылка на документацию или каталог UI-компонентов;
- `STORYBOOK` — ссылка на Storybook.

Источник UI не является готовым приложением и сам по себе не может завершить этап `VISUAL_PROTOTYPE`. Даже если Storybook содержит интерактивные stories, он остаётся каталогом компонентов.

Найденный источник сначала регистрируется как кандидат `DISCOVERED_REFERENCE` через `tools/register_ui_candidate.py`, затем Product Manager выбирает его через `tools/record_ui_source.py`. Для Storybook и библиотеки компонентов нужно перечислить реально просмотренные компоненты.

Готовое кликабельное приложение учитывается отдельно через `applicationMode`:

- `EXISTING_CLICKABLE_APP` — материализуется существующее приложение;
- `GENERATED_PROTOTYPE` — материализуется специально созданный визуальный прототип.

Этап `VISUAL_PROTOTYPE` завершается только после появления локального кликабельного HTML-приложения в `visual-prototype/` и успешной проверки обязательного пользовательского пути.
